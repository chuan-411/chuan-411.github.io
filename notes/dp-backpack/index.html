背包 DP 全家桶：01 / 完全 / 多重 / 分组

2026.09.12 · 1 分钟 · ★★☆☆☆ · 专栏「DP 手帳」 · #动态规划 #背包 #入门 #模板

背包是动态规划里最像「生活」的一类问题：预算有限，东西很多，你要决定带什么走。

一张表看懂四种背包

设 f[j] 表示容量为 j 时的最优值，w 是重量，v 是价值。

类型每种物品循环方向关键句
01 背包最多 1 个j 倒序每个物品只能用一次
完全背包无限个j 正序用完还能再用
多重背包有限个 c二进制拆分或单调队列把 c 拆成 1,2,4,…
分组背包每组选 1 个先组，再倒序容量，再组内物品同组互斥

01 背包

int f[N];
for (int i = 1; i <= n; ++i)
    for (int j = m; j >= w[i]; --j)   // 倒序！否则同一件会被拿两次
        f[j] = max(f[j], f[j - w[i]] + v[i]);

为什么倒序有效：f[j] 只会从「上一轮」的 f[j - w] 转移，倒序保证 f[j - w] 还没被这一件物品更新过。

完全背包

for (int i = 1; i <= n; ++i)
    for (int j = w[i]; j <= m; ++j)   // 正序：允许本层反复使用
        f[j] = max(f[j], f[j - w[i]] + v[i]);

正序时 f[j - w] 可能已经是「装过第 i 件」的状态，等价于无限取。

多重背包：二进制拆分

把 c 个物品拆成 1,2,4,…,rest 这些「包」，每个包当 01 物品处理。正确性来自二进制能表示 [0, c] 的任何数量。

for (int i = 1; i <= n; ++i) {
    int c = cnt[i], k = 1;
    while (c > 0) {
        int take = min(k, c);
        for (int j = m; j >= take * w[i]; --j)
            f[j] = max(f[j], f[j - take * w[i]] + take * v[i]);
        c -= take, k <<= 1;
    }
}

复杂度从 O(n·m·c) 降到 O(n·m·log c)。

如果 m 很大而 c 很小，单调队列优化能把 O(n·m·log c) 再压到 O(n·m)，但大多数题二进制拆分就够用了。

分组背包

for (int g = 1; g <= G; ++g)
    for (int j = m; j >= 0; --j)
        for (auto [w, v] : group[g])
            if (j >= w) f[j] = max(f[j], f[j - w] + v);

注意「容量倒序」在组的外面、物品的里面。写反就会让一组里选了两个。

三个常见坑

  1. 初始化：求「恰好装满」时 f[0]=0，其余 -INF；求「不超过容量」时全部 0。
  2. 倒序写成 j >= 0：f[j - w[i]] 越界前要先判 j >= w[i]。
  3. 方案数背包：把 max 换成加法，且注意「物品在外、容量在内」数的是组合数，反过来数的是排列数。

一句话总结

背包的骨架只有一句：用容量做状态，用「能不能重复选」决定循环方向。 剩下的都是这句话的变体。
