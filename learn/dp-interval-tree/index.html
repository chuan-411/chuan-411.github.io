区间 DP 与树形 DP

区间 DP 按长度从小到大合并断点，树形 DP 按子树自底向上合并状态。 · 区间 DP O(n³)，树形 DP O(n)

一句话理解

区间 DP 问的是「把一段区间合并成一堆的最小代价」，于是按长度从小到大枚举，把区间切成两半再拼起来；树形 DP 问的是「子树内部怎么决策」，于是后序遍历，把儿子的答案合并给父亲。

核心思想

区间 DP 的状态是 f[l][r]：把区间 [l, r] 处理完的最优值。转移一定枚举「最后一次合并的断点」k：

f[l][r] = min{ f[l][k] + f[k+1][r] + cost(l, r) }，k 取 l 到 r-1

cost 是这次合并的代价（石子合并里就是区间和，靠前缀和 O(1) 求出）。枚举顺序是关键：f[l][r] 依赖更短的区间，所以必须按 len = r-l+1 从小到大推，len = 1 是边界。

环形问题（石子排成一圈）用断环成链：把数组复制一倍，长度变成 2n，答案取 min/max{ f[i][i+n-1] }，i 从 1 到 n。这样每条环上的路径都被某段长度为 n 的区间覆盖。

树形 DP 的状态挂在节点上，先递归儿子，再用儿子更新自己。以「没有上司的舞会」为例，f[u][0/1] 表示 u 不来 / 来时子树的最大快乐值：

f[u][0] = Σ max(f[v][0], f[v][1])   // u 不来，儿子随意
f[u][1] = val[u] + Σ f[v][0]        // u 来了，儿子都不能来

答案为 max(f[root][0], f[root][1])。无根树要自己定根，用「父节点」防止走回头路。

区间 DP 的依赖方向（len 递增）：
[1,1] [2,2] [3,3] [4,4]
   [1,2]   [2,3]   [3,4]
      [1,3]     [2,4]
         [1,4]        ← 最后才算

模板与实现

// 区间 DP 框架（石子合并取最小值；环已复制成 2n）
const long long INF = (long long)4e18;
vector<long long> pre(2 * n + 1, 0);                     // 前缀和
for (int i = 1; i <= 2 * n; ++i) pre[i] = pre[i-1] + a[i];

vector<vector<long long>> f(2 * n + 2, vector<long long>(2 * n + 2, INF));
for (int i = 1; i <= 2 * n; ++i) f[i][i] = 0;            // 单个区间无需合并

for (int len = 2; len <= n; ++len)                       // 长度从小到大
    for (int l = 1; l + len - 1 <= 2 * n; ++l) {
        int r = l + len - 1;
        for (int k = l; k < r; ++k) {                    // 断点
            long long cost = pre[r] - pre[l - 1];
            f[l][r] = min(f[l][r], f[l][k] + f[k+1][r] + cost);
        }
    }

long long ans = INF;
for (int i = 1; i <= n; ++i) ans = min(ans, f[i][i + n - 1]);
// 树形 DP：没有上司的舞会
vector<int> g[MAXN], val;
int f[MAXN][2];

void dfs(int u, int fa) {
    f[u][1] = val[u]; f[u][0] = 0;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        f[u][0] += max(f[v][0], f[v][1]);   // u 不来
        f[u][1] += f[v][0];                 // u 来，儿子不能来
    }
}

复杂度与边界

  • 区间 DP：状态 O(n²)、转移 O(n)，合计 O(n³)；n ≤ 500 可行，n 到 2000 就要四边形不等式优化。
  • 环形必须把数组开成 2n，len 最大只取到 n（不是 2n），答案在 [i, i+n-1] 上取。
  • 树形 DP：O(n) 或 O(n × 状态数)；树形背包合并是 O(n·V²) 量级，注意剪枝。
  • 初始化：求最小值用大 INF 且 f[i][i] = 0；求最大值用 -INF 或 0，取决于是否允许空区间。

易错点

  • 枚举顺序错：len 必须在外层，先算长区间会用到还没算的短区间。
  • 环形忘了复制：只开 n 会漏掉跨过首尾的合并，答案偏小。
  • 答案取错区间：复制之后要在 [i, i+n-1] 上取最优，不是 f[1][2n]。
  • 断点范围写错：k 从 l 到 r-1，写成 r 会访问到 f[r+1][r] 这种非法状态。
  • 树形 DP 只建单向边：无根树要建双向边并用父节点防回头，否则死递归。
  • 递归爆栈：n = 1e5 的链要改成按拓扑序递推或手写栈。

例题拆解

石子合并（Luogu P1880）：n 堆石子围成一圈，每次只能合并相邻两堆，得分为两堆之和，求最小与最大总得分。转化：环形转链，数组复制成 2n。做法：区间 DP 分别求 min 与 max，最后在 f[i][i+n-1] 上取最优。复杂度 O(n³)，n ≤ 100 稳稳通过。

没有上司的舞会（Luogu P1352）：树上的点带权值，选了父亲就不能选儿子，求最大权独立集。做法：f[u][0/1] 两个状态，后序 DFS 合并儿子，先找出没有上司的根节点，答案取根的两个状态中较大者。复杂度 O(n)。能量项链 P1063 是区间 DP 的环形变体，只是合并代价换成了三段相乘。

自测清单

  • 能写出区间 DP 的三层循环顺序并解释原因
  • 知道环形问题为什么要复制数组、答案怎么取
  • 能独立推出树形 DP 的两条转移方程
  • 能判断一道题该按区间设状态还是按子树设状态
  • 知道 n 多大时 O(n³) 会超时
