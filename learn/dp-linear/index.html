动态规划 / 提高 / 第 1 节

线性 DP 与背包

先定状态再想转移：01 背包倒序、完全背包正序，LIS 用贪心加二分。 · 背包 O(nV)，LIS O(n log n)

一句话理解

动态规划就是把大问题拆成小问题，并把小问题的答案存下来复用。线性 DP 的特点是状态沿着一个方向推进——下标、容量或长度——每一步只依赖前面已经算好的几步。

核心思想

设计一个 DP 只需要回答四个问题：阶段（按什么顺序推进）、状态（用什么量刻画当前局面）、决策（这一步能怎么选）、转移（从哪个旧状态来）。再加一条硬要求：无后效性——状态一旦确定，未来的决策就与「怎么走到这里」无关。

以 01 背包为例。f[i][j] 表示前 i 件物品、容量为 j 时的最大价值：

f[i][j] = max( f[i-1][j], f[i-1][j-w[i]] + v[i] )

即「不选第 i 件」或「选它，并从容量 j-w[i] 转移」。把第一维滚掉后，f[j] 必须倒序枚举：正序时 f[j-w[i]] 已被本轮更新过，等于允许同一件物品反复选，那就变成完全背包了。反过来，完全背包正序枚举恰好就是它要的语义。

LIS 有两层做法。O(n²) 的 f[i] = max(f[j]) + 1 (a[j] < a[i]) 直观但慢；O(n log n) 的做法维护 tails[len]：长度为 len 的上升子序列，结尾最小能是多少。tails 天然单调递增，新元素用 lower_bound 找到第一个不小于它的位置替换掉——替换不会让答案变差，因为结尾更小只会更容易接上后面的数。

a = 1 3 5 2 4 6
tails 变化：
[1] → [1,3] → [1,3,5] → [1,2,5] → [1,2,4] → [1,2,4,6]
                          ↑ 2 顶掉 3：长度不变，但结尾更优

模板与实现

// 01 背包：n 件物品，容量 V
vector<long long> f(V + 1, 0);
for (int i = 1; i <= n; ++i)
    for (int j = V; j >= w[i]; --j)        // 倒序，保证每件只用一次
        f[j] = max(f[j], f[j - w[i]] + v[i]);
// 答案：f[V]
// 完全背包：只把容量循环改成正序
for (int i = 1; i <= n; ++i)
    for (int j = w[i]; j <= V; ++j)        // 正序，允许重复选
        f[j] = max(f[j], f[j - w[i]] + v[i]);
// LIS（严格上升），O(n log n)
int lis(const vector<int>& a) {
    vector<int> tails;                      // 始终单调递增
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;                       // 用更小的结尾替换
    }
    return (int)tails.size();
}

要「不下降」就把 lower_bound 换成 upper_bound；要最长下降序列，把数组取负后照做。

复杂度与边界

  • 01 / 完全背包：O(nV) 时间、O(V) 空间；n·V 超过 1e8 就要考虑单调队列优化或换思路。
  • LIS：O(n log n)。O(n²) 的写法只在小数据、或需要输出具体方案时使用。
  • 「恰好装满」类问题要把 f[0] = 0、其余全部置 -INF，最后 f[V] < 0 表示无解。
  • 价值与容量之积可能超过 int，f 一律开 long long。

易错点

  • 01 背包正序枚举：容量循环方向反了，物品会被无限次使用，答案偏大。
  • 初值语义混用：求最大值时初始化 0；求「恰好装满」才用 -INF，混用必错。
  • LIS 用错二分：严格上升用 lower_bound，不下降用 upper_bound，混淆会多算或漏算。
  • 答案取错位置：多数线性 DP 的答案是 max(f[0..V])，不是 f[V]。
  • 状态少记一维：漏了「用了几个」之类约束，转移会串味，先检查无后效性再写。
  • int 溢出：f[j-w[i]] + v[i] 在 1e9 级别会溢出，先开 long long。

例题拆解

采药（Luogu P1048）：有 T 的时间、M 株草药，每株耗时 t[i]、价值 v[i]，每株只能采一次，求最大总价值。这正是一个容量为 T、物品数为 M 的 01 背包，倒序枚举时间即可，复杂度 O(MT)。同类的数字三角形 P1216 换了个形态：f[i][j] = max(f[i-1][j-1], f[i-1][j]) + a[i][j]，从上往下推，答案在最后一行取最大。

导弹拦截（Luogu P1020）：第一问求最长不上升子序列长度；第二问求最少需要几套拦截系统，也就是最小链覆盖。由 Dilworth 定理，它等于最长上升子序列长度。做法：两问都用 O(n log n) 的贪心加二分——第一问把 a[i] 取负后求不下降子序列，第二问直接求 LIS。复杂度 O(n log n)。

自测清单

  • 能说出 01 背包为什么要倒序枚举容量
  • 能把二维背包正确滚成一维
  • 能解释 tails 数组为什么单调
  • 会用 Dilworth 定理把「最少链数」变成 LIS
  • 能判断一道题的状态是否满足无后效性
