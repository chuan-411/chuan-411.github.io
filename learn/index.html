✿基础算法

7 节
入门 01

复杂度分析

不看机器看增长：先估量级，再决定这个想法能不能写。

常见为 O(1) ~ O(n log n)，据此反推可承受的数据范围 50 题
✓ 已掌握
入门 02

枚举、模拟与构造

想不清就穷举：先保证不重不漏，再想办法少枚举一点。

O(枚举量)，剪枝与倒序枚举常把 n² 压成 n 80 题
✓ 已掌握
入门 03

排序与贪心

排序把无序变成结构，贪心则在这份结构上每次只拿当下最好的。

排序 O(n log n)；贪心多为 O(n log n)（排序 + 一次扫描）或 O(n log n)（堆） 80 题
✓ 已掌握
入门 04

二分查找与二分答案

把「单调性」换成对数：查找是缩小范围，答案是缩小可行域。

O(log n)，答案二分时乘上一次 check 的代价 75 题
✓ 已掌握
入门 05

前缀和与差分

前缀和把「一段」压成「两点相减」，差分把「一段修改」压成「两个端点」。

预处理 O(n)，单次区间查询/区间修改 O(1)，还原 O(n) 97 题
✓ 已掌握
入门 06

双指针与滑动窗口

两个指针只朝一个方向走，用不回退换掉一层循环。

O(n)，每个元素最多被左右指针各访问一次 71 题
✓ 已掌握
入门 07

位运算与二进制枚举

一个整数就是一排开关：按位操作是 O(1) 的并行，二进制枚举是 2ⁿ 的穷举。

单次位运算 O(1)；二进制枚举 O(2ⁿ · n)（n ≤ 20 量级） 62 题
✓ 已掌握

✿数据结构

9 节
入门 01

栈、队列与单调结构

栈管「最近的」，队列管「最早的」，单调栈队列管「下一个更大」。

基本操作 O(1)；单调栈/单调队列整体 O(n) 88 题
✓ 已掌握
入门 02

竞赛中的 STL

把「手写容器」的时间省下来：用对容器，代码短一半，风险也少一半。

vector 均摊 O(1)；set/map 每次 O(log n)；priority_queue O(log n) 81 题
✓ 已掌握
入门 03

哈希表与字符串哈希

用一次取模把大值域压进小数组，再用冲突处理把期望 O(1) 稳住。

期望 O(1) 插入/查询；字符串哈希预处理 O(n)、子串比较 O(1) 73 题
✓ 已掌握
入门 04

堆与优先队列

只维护「最值」的完全二叉树：把找最值从 O(n) 压到 O(log n)。

插入与删除堆顶 O(log n)，取最值 O(1)，自底向上建堆 O(n) 95 题
✓ 已掌握
入门 05

高精度运算

把小学竖式翻译成数组：一位一位算，一位一位进位，就不怕溢出。

加/减 O(n)，高精乘高精 O(n²)，压位后常数降为约 1/9 91 题
✓ 已掌握
提高 06

并查集

只回答「我们是不是一伙的」：用森林表示集合，路径压缩后近似 O(1)。

路径压缩 + 按大小合并，单次操作均摊 O(α(n)) 80 题
✓ 已掌握
提高 07

树状数组

用 lowbit 把前缀和拆成 log n 段，改一个点只动 log n 个格子。

单点修改、前缀查询均 O(log n)；空间 O(n) 83 题
✓ 已掌握
提高 08

线段树与懒标记

把区间切成 log n 个整块，改动先记成标记，等到要往下走时才推给孩子。

建树 O(n)，单次区间修改/查询 O(log n)，空间 O(n) 83 题
✓ 已掌握
提高 09

ST 表与区间最值

两段长度 2^k 的重叠区间就能盖住任意区间，静态最值 O(1) 回答。

预处理 O(n log n)，单次查询 O(1)，空间 O(n log n) 83 题
✓ 已掌握

✿图论

5 节
提高 01

图论基础与遍历

先把图存成表，再用 DFS/BFS 沿着边走完它能到的每一个点。

存图 O(n + m)，一次 DFS/BFS 遍历 O(n + m) 81 题
✓ 已掌握
提高 02

最短路

非负边用堆优化 Dijkstra，有负边用 Bellman-Ford，多源小图用 Floyd。

堆优化 Dijkstra O((n+m) log m)；Bellman-Ford/SPFA 最坏 O(nm)；Floyd O(n³) 79 题
✓ 已掌握
提高 03

最小生成树与二分图

最小生成树靠切分性质贪心加边，二分图靠染色判定、增广路求匹配。

Kruskal O(m log m)；Prim O(n²)；匈牙利 O(nm) 82 题
✓ 已掌握
进阶 04

Tarjan 与强连通分量

一次 DFS 记 dfn 与 low，用 low 判定强连通分量、割点与割边。

O(n + m) 71 题
✓ 已掌握
进阶 05

LCA 与倍增

用 2^k 级祖先把两点抬到同一高度，再一起跳到 LCA 的下一层。

预处理 O(n log n)，单次查询 O(log n) 70 题
✓ 已掌握

✿动态规划

3 节
提高 01

线性 DP 与背包

先定状态再想转移：01 背包倒序、完全背包正序，LIS 用贪心加二分。

背包 O(nV)，LIS O(n log n) 88 题
✓ 已掌握
提高 02

区间 DP 与树形 DP

区间 DP 按长度从小到大合并断点，树形 DP 按子树自底向上合并状态。

区间 DP O(n³)，树形 DP O(n) 93 题
✓ 已掌握
进阶 03

状压 DP 与数位 DP

状压把集合压进二进制位，数位 DP 从高位逐位决策并记忆化。

状压 O(n·S²)；数位 DP O(位数 × 状态数 × 10) 78 题
✓ 已掌握

✿字符串

2 节
提高 01

KMP 与字符串匹配

用 nxt 数组记住已匹配前缀的最长 border，失配时主串指针不回退。

O(n + m) 82 题
✓ 已掌握
进阶 02

字典树与 AC 自动机

用公共前缀压成一棵树，再给每个结点挂一条失配指针。

建树 O(∑|s|)，匹配 O(|T| + 结点数) 93 题
✓ 已掌握

✿数学

4 节
进阶 01

数论基础

一切从唯一分解出发：筛法拿质因子，exgcd 与逆元做模意义除法。

线性筛 O(n)，快速幂 O(log b)，exgcd O(log min(a,b)) 82 题
✓ 已掌握
进阶 02

组合计数与容斥

先分类、再分步，最后把重复数的部分减回去。

阶乘预处理 O(n) 后单次 O(1)；Lucas O(p + log_p n) 81 题
✓ 已掌握
进阶 03

博弈论与 SG 函数

必败态是「怎么走都到必胜态」，SG 值把多个子游戏异或成一个。

SG 打表 O(状态数 × 转移数)，Nim 判定 O(n) 81 题
✓ 已掌握
提高 04

矩阵快速幂

把递推写成「状态向量乘转移矩阵」，再用快速幂跳过中间项。

O(k³ log n)，k 为矩阵阶数 96 题
✓ 已掌握

✿进阶专题

3 节
进阶 01

计算几何基础

一切从叉积出发：定方向、判左右、算面积，再谈凸包与分治。

凸包 O(n log n)，最近点对 O(n log n) 81 题
✓ 已掌握
省选 02

树链剖分

按重儿子把树切成链，让每条路径只落在 O(log n) 段连续区间上。

预处理 O(n)，路径操作 O(log² n)，子树操作 O(log n) 62 题
✓ 已掌握
省选 03

网络流初步

在残量网络上不断找增广路，找不到时流量就是最大流。

Dinic 一般 O(n²m)，单位容量网络接近 O(m√n) 61 题
✓ 已掌握
