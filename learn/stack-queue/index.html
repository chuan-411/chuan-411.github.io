栈、队列与单调结构

栈管「最近的」，队列管「最早的」，单调栈队列管「下一个更大」。 · 基本操作 O(1)；单调栈/单调队列整体 O(n)

一句话理解

栈像一摞盘子，只能从最上面拿，天生适合处理「最近还没配对的」东西；队列像排队买饭，先来先服务，适合按层推进的搜索。两者都只允许在端点进出。

核心思想

栈（LIFO） 的经典用途是配对与回退：括号匹配、消除相邻相同元素、表达式求值、DFS 非递归。判据是「后出现的问题必须先解决」。

队列（FIFO） 的经典用途是按顺序推进：BFS 逐层扩展、模拟排队。BFS 能求最短步数，靠的是队列保证「先入队的距离不大于后入队的」。

表达式求值有两条路：一是转后缀再求值，遇数字入栈、遇运算符弹出两个数算完压回，天然无需括号；二是中缀双栈，遇运算符先结算栈顶所有优先级不低于它的（同级左结合也要算）。

单调栈解决「每个元素左/右第一个比它大（小）的元素」。以「下一个更大元素」为例：维护值单调递减的栈，新元素进来时弹出所有比它小的栈顶，被弹出者的答案就是当前元素。每个元素进出各一次，整体 O(n)；栈里存下标而非值，才能算距离。

单调队列是单调栈加上过期机制，用于滑动窗口最值：队尾按值单调，队首按时间过期。两者都是「用单调性换掉一层循环」的典型。

单调栈求下一个更大（值 3 1 4 1 5）：
  读 3     栈 [3]
  读 1     栈 [3,1]
  读 4     弹出 1（答案 4）、弹出 3（答案 4），栈 [4]
  读 1     栈 [4,1]
  读 5     弹出 1、弹出 4，栈 [5]

模板与实现

// 1. 数组模拟栈 + 后缀表达式求值（数字以 '.' 结尾，整串以 '@' 结尾）
int evalSuffix(const string& s) {
    long long st[100005]; int top = 0;
    long long num = 0; bool has = false;
    for (char c : s) {
        if (c == '@') break;
        if (isdigit(c)) { num = num * 10 + (c - '0'); has = true; }
        else if (c == '.') { st[top++] = num; num = 0; has = false; }
        else {
            long long b = st[--top], a = st[--top];   // 先弹右操作数
            long long r = (c == '+') ? a + b : (c == '-') ? a - b
                        : (c == '*') ? a * b : a / b;
            st[top++] = r;
        }
    }
    return (int)st[top - 1];
}

// 2. 中缀表达式求值：双栈（只演示 + * 与括号的骨架）
int prec(char op) { return (op == '+' || op == '-') ? 1 : 2; }

void apply(stack<long long>& num, char op) {
    long long b = num.top(); num.pop();
    long long a = num.top(); num.pop();
    if (op == '+') num.push(a + b);
    else if (op == '-') num.push(a - b);
    else if (op == '*') num.push((a * b) % 10000);
    else num.push(a / b);
}

// 3. 单调栈：每个位置右边第一个更大元素的下标
vector<int> nextGreater(vector<int>& a) {
    int n = a.size();
    vector<int> res(n, -1), st;                 // st 存下标，值单调递减
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && a[st.back()] < a[i]) {
            res[st.back()] = i;                 // i 就是它的下一个更大
            st.pop_back();
        }
        st.push_back(i);
    }
    return res;
}

中缀求值里 ( 无条件入栈；) 则不断 apply 直到弹出 ( 并丢弃之。运算符栈顶是 ( 时，任何运算符都不能越过它。

复杂度与边界

  • 基本操作（push/pop/front）均摊 O(1)。
  • 后缀求值 O(n)，中缀双栈 O(n)。
  • 单调栈、单调队列 O(n)，空间 O(n)。
  • 数组模拟栈比 std::stack 快，代价是自己管 top；n 较大时优先数组。
  • 表达式的中间结果可能超过 int，乘法用 long long 或按题目要求取模。

易错点

  • 弹栈顺序写反：后缀表达式先弹 b 再弹 a，必须写 a - b、a / b，写成 b - a 则减法除法全错。
  • 多位数字解析错：后缀表达式用 . 分隔数字，必须用累加器读完整个数再入栈，不能逐位入栈。
  • 同级运算符没先算：2 - 3 + 4 若让 + 越过 - 会算成 2 - 7，同级左结合，必须 >= 才弹。
  • 括号处理漏掉：) 弹出后要把 ( 也弹掉，否则它会被当运算符。
  • 取模后出现负数：减法取模写 (a - b % MOD + MOD) % MOD，直接 % 会得到负值。
  • stack/queue 没有 clear()：多组数据只能重新声明或循环 pop，且没有迭代器。
  • 数组模拟栈开小：top 可能达到 n，数组至少开 n + 5。

例题拆解

后缀表达式（Luogu P1449）

题意：给出后缀表达式，数字以 . 结尾、整串以 @ 结尾，运算符为 + - * /，求值。

转化：后缀求值顺序与优先级无关——运算符作用的正是最近压入且未被用掉的两个数，即栈顶两元素。

做法：从左扫到 @。遇数字累加到 num，遇 . 入栈并清零；遇运算符弹出 b 再弹出 a，把 a op b 压回，最后栈顶即答案。先弹出的是右操作数。

复杂度：时间 O(n)，空间 O(n)，每个数进出栈各一次。

表达式求值（Luogu P1981）

题意：给定只含 + 与 *、无括号的表达式，求其对 10000 取模的结果。

转化：没有括号意味着优先级只有两层，可以用 + 把表达式切成若干「乘积块」，块内连乘。

做法：维护 ans（已确定的加法部分）与 term（当前乘积块）。读数字乘进 term，读 + 就把 term 并入 ans 并清空，读 * 继续累积；扫完加上最后的 term，全程对 10000 取模。

复杂度：时间 O(n)，滚动写法空间 O(1)。

自测清单

  • 能说清「什么信号出现时该用栈而不是队列」
  • 能默写后缀表达式求值，并记住先弹右操作数
  • 能解释中缀求值里同级运算符为什么必须立即结算
  • 会用单调栈求「下一个更大元素」并说明总复杂度是 O(n)
  • 知道 stack/queue 为什么没有 clear() 与迭代器
