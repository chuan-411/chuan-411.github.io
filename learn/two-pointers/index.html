双指针与滑动窗口

两个指针只朝一个方向走，用不回退换掉一层循环。 · O(n)，每个元素最多被左右指针各访问一次

一句话理解

双指针是用「两个变量标记一段区间」，并且保证它们永远不往回走。这样每个元素最多进区间一次、出区间一次，两层循环就被摊平成一层。

核心思想

按指针的移动方向分三类：

  1. 相向双指针：l 从左往右、r 从右往左。典型是有序数组求两数之和——a[l] + a[r] 偏小就 ++l，偏大就 --r。正确性来自单调性：如果当前和偏小，那么 a[l] 与任何 r' ≤ r 的和只会更小，所以 a[l] 可以整体排除。
  2. 同向双指针（滑动窗口）：r 负责扩大窗口，l 负责在窗口不合法时收缩。它要求合法性关于端点单调：窗口 [l, r] 满足条件时，[l', r]（l' > l）可能不满足，但 [l, r']（r' > r）一定还满足。只有满足这个方向性，l 才能只增不减。
  3. 快慢指针：链表找中点、判环，本质是让两个指针以不同速度走。

滑动窗口的写法固定成三段：r 进来、更新状态、while (不合法) { 移出 l; ++l; }、用当前窗口更新答案。核心是状态只增删不重算：用 cnt[x] 记窗口内颜色 x 的个数、distinct 记「有多少种颜色个数非零」。加入时 cnt[x] 由 0 变 1 则 ++distinct，移除时由 1 变 0 则 --distinct。千万别每次重扫窗口数种类。

单调队列是滑动窗口求最值的专用结构：维护一个下标队列，值单调递减。新元素入队前弹掉队尾所有不大于它的（既更旧又更小，永不可能是答案）；队首超出窗口就弹出。队首永远是当前窗口最大值，整体 O(n)。

窗口 [l, r] 向右滑：
  l→  1 2 3 4 5 6 7
  r→      [-----]
        每次 r 右移一格，l 只在不合法时右移
  区间长度 = r - l + 1

模板与实现

// 1. 相向双指针：有序数组中找两数之和等于 target
bool twoSum(vector<int>& a, int target) {
    sort(a.begin(), a.end());
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target) return true;
        if (s < target) ++l;          // 和偏小，左指针右移
        else --r;                     // 和偏大，右指针左移
    }
    return false;
}

// 2. 滑动窗口：最短的、包含全部 m 种元素的区间
int shortestCover(vector<int>& a, int m) {   // a[i] ∈ [1, m]
    vector<int> cnt(m + 1, 0);
    int distinct = 0, l = 0, ans = INT_MAX;
    for (int r = 0; r < (int)a.size(); ++r) {
        if (++cnt[a[r]] == 1) ++distinct;      // 新颜色进入窗口
        while (distinct == m) {                // 窗口已合法，尝试收缩
            ans = min(ans, r - l + 1);
            if (--cnt[a[l]] == 0) --distinct;  // 某颜色被移空
            ++l;
        }
    }
    return ans == INT_MAX ? -1 : ans;
}

// 3. 单调队列：窗口最大值
vector<int> windowMax(vector<int>& a, int k) {
    deque<int> q;                              // 存下标，值单调递减
    vector<int> res;
    for (int i = 0; i < (int)a.size(); ++i) {
        while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();  // 更旧且更小，无用
        q.push_back(i);
        if (q.front() <= i - k) q.pop_front(); // 队首超出窗口
        if (i >= k - 1) res.push_back(a[q.front()]);
    }
    return res;
}

复杂度与边界

  • 时间 O(n)：l 与 r 各单调移动至多 n 次，内层 while 的总次数也是 O(n)。
  • 空间 O(1)（除计数数组 O(V)）或 O(k)（单调队列）。
  • 前提是窗口合法性单调，且计数数组的 V 不太大；V 很大时改用 unordered_map 计数。
  • 含负数的「和 ≥ S 的最短子数组」不满足单调性，双指针失效，需要前缀和 + 二分或单调队列。

易错点

  • 不验证单调性就滑窗：l 右移后条件必须只会单向变化；「和最接近 S」这类问题不能直接滑。
  • 计数数组整体清空：memset(cnt) 会把 O(n) 优化打回 O(nV)，只该改 a[l] 那一项。
  • distinct 更新条件写反：是「计数由 0 变 1」加一、「由 1 变 0」减一，写成 cnt[x] == 1 之外的条件都会错。
  • 答案初值取 0：求最短区间时初值必须是 INF，取 0 会把答案永远压成 0。
  • 长度公式写错：闭区间长度是 r - l + 1，半开区间才是 r - l。
  • 单调队列不判过期：只按值弹队尾、忘了 q.front() <= i - k 出队，队首会留在窗口外。
  • 单调队列存值不存下标：存值就无法判断是否过期，必须存下标。

例题拆解

逛画展（Luogu P1638）

题意：一幅画由 n 个格子组成，每个格子画着某位画家的画（编号 1~m），求一段最短的连续区间，使得区间内包含全部 m 位画家的作品。

转化：这是「最短覆盖区间」模型。区间越长越容易覆盖全部画家，越短越可能缺画家——合法性关于长度单调，正好用滑动窗口。

做法：r 逐格右移并把 a[r] 计数加一；当 distinct == m 时用当前长度更新答案，再不断右移 l 收缩直到窗口不合法，全程记录最优端点。

复杂度：时间 O(n)，空间 O(m)；每个格子最多进出窗口各一次。

滑动窗口（Luogu P1886）

题意：长度为 n 的序列，给定窗口大小 k，输出每个长度为 k 的窗口中的最小值与最大值。

转化：窗口每次只右移一格，只有一个元素进出，所以不必重算整个窗口，只需一个能快速取最值、又能删除过期元素的结构。

做法：用单调队列。求最大值时维护值递减的下标队列：新元素入队前弹掉队尾所有不大于它的元素，队首若已滑出窗口则弹出，此时队首即窗口最大值。最小值把比较符反过来即可，两遍 O(n)。

复杂度：时间 O(n)（每个下标最多入队出队各一次），空间 O(k)。

自测清单

  • 能说清相向双指针为什么可以「整块排除」掉一个端点
  • 能写出滑动窗口的三段式骨架并保持 l 单调
  • 能证明滑动窗口的总复杂度是 O(n) 而不是 O(n²)
  • 能默写单调队列求窗口最大值的四行核心逻辑
  • 能判断一道题是否满足「窗口合法性单调」
