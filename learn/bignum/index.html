高精度运算

把小学竖式翻译成数组：一位一位算，一位一位进位，就不怕溢出。 · 加/减 O(n)，高精乘高精 O(n²)，压位后常数降为约 1/9

一句话理解

当 long long 也装不下答案时，就把数字拆成一位一位放进数组，像小学笔算那样对齐、相加、进位。高精度不是新算法，只是把手工竖式写成循环。

核心思想

存法：用 vector<int> 存十进制位，低位在前。这样个位永远在下标 0，加法从下标 0 开始对齐，进位不够就在末尾 push_back，不用整体挪动。读入时倒着扫一遍字符串即可。

加减：逐位相加并维护进位 t，写回 t % 10，再让 t /= 10；循环条件里要带上 t，否则最高位的进位会丢。减法先保证被减数不小于减数，逐位相减，不够就向高位借 1。

乘法：高精乘低精是 O(n) 的逐位乘加；高精乘高精是 O(n²)，核心是 c[i+j] += a[i] * b[j]。先把所有乘积累加完，最后统一扫一遍处理进位，这比边乘边进位更不容易错，也与竖式的「先写部分积再相加」一致。正确性来自十进制展开：(Σa[i]10^i)(Σb[j]10^j) = Σ a[i]b[j]10^{i+j}，每位系数与进位方式唯一。

压位：把 9 个十进制位塞进一个 int，以 1e9 为基。位数缩短到 1/9，乘法常数随之下降；代价是进位时要用 long long 承接，输出时除最高位外都要补足 9 位前导零。

高精除单精从高位往低位试商即可；高精除高精需要逐位试商（或二分商），代码量陡增，能用其他方法绕开就绕开。

模板与实现

1. 读入、加法与比较

vector<int> readNum(const string& s) {     // 低位在前
    vector<int> a;
    for (int i = (int)s.size() - 1; i >= 0; --i) a.push_back(s[i] - '0');
    while (a.size() > 1 && a.back() == 0) a.pop_back();
    return a;
}
vector<int> add(const vector<int>& a, const vector<int>& b) {
    vector<int> c;
    int t = 0;
    for (size_t i = 0; i < a.size() || i < b.size() || t; ++i) {
        if (i < a.size()) t += a[i];
        if (i < b.size()) t += b[i];
        c.push_back(t % 10);
        t /= 10;
    }
    return c;
}

2. 高精乘高精（先累加，后统一进位）

vector<int> mul(const vector<int>& a, const vector<int>& b) {
    vector<long long> c(a.size() + b.size(), 0);   // n + m 位足够
    for (size_t i = 0; i < a.size(); ++i)
        for (size_t j = 0; j < b.size(); ++j)
            c[i + j] += 1LL * a[i] * b[j];
    long long carry = 0;
    for (size_t i = 0; i < c.size(); ++i) {
        c[i] += carry;
        carry = c[i] / 10;
        c[i] %= 10;
    }
    while (c.size() > 1 && c.back() == 0) c.pop_back();
    return vector<int>(c.begin(), c.end());
}

复杂度与边界

  • 加法、减法、乘低精、除低精都是 O(n)。
  • 高精乘高精 O(n²)，位数上万时要用 FFT/NTT，普通题目不需要。
  • 空间 O(n + m)；压位后同样位数的数组长度缩小 9 倍。
  • 位数估算：n! 的位数约 n log10(n/e)，几百以内都能用 O(n²) 乘法勉强过关。
  • int 承接到 1e9 基的乘积会溢出，压位时一律用 long long。

易错点

  • 忘记低位在前：按正常顺序存会让进位方向反过来，push_back 也无法补最高位。
  • 输出前导零：0 + 0 与高位清零不彻底都会打印出 000，末尾要去零、但要保留至少一位。
  • 减法出现负数：先比较大小并交换，否则借位链会崩。
  • 乘法数组开小：结果最多 n + m 位，开 n + m 而不是 n + m - 1。
  • 压位进位溢出：1e9 * 1e9 超过 int，累加器必须是 long long。
  • 压位输出不补零：除最高位外每位都要补到 9 位，否则 1 000000001 会被打印成 11。

例题拆解

A*B Problem（Luogu P1303）：求两个非负大整数的乘积。 转化：高精乘高精的标准形态，读入为字符串，位数可达数千。 做法：倒序存位，双重循环累加 c[i+j] += a[i]*b[j]，最后统一进位并去掉高位零。输入可能含 0，要保证结果为单个 0。 复杂度：O(nm)。

阶乘之和（Luogu P1009）：求 1! + 2! + ... + n!。 转化：不必每次从头乘，用「高精乘低精」维护当前的 i!，再用高精加法累加。 做法：fac = fac * i（逐位乘并处理进位），sum = sum + fac，循环 i = 1..n。这是典型的「高精 + 递推」，n 到 50 时结果有六十多位，long long 早就不够。 复杂度：O(n²)，总位数不大的实际常数很小。

自测清单

  • 能默写低位在前的加法和进位循环
  • 能解释乘法为什么先累加再统一进位
  • 知道压位为什么能提速、进位为什么要用 long long
  • 能正确处理结果为 0 与前导零
  • 能估算 n! 的位数并判断该用哪种精度方案
