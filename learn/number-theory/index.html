数学 / 进阶 / 第 1 节

数论基础

一切从唯一分解出发：筛法拿质因子，exgcd 与逆元做模意义除法。 · 线性筛 O(n)，快速幂 O(log b)，exgcd O(log min(a,b))

一句话理解

数论结论大多建在唯一分解定理上：每个整数拆成质数幂的乘积，拆法是唯一的。于是问题往往归结成两件事——怎么快速拿到质因子（筛法），怎么在模意义下做除法（逆元）。

核心思想

**线性筛（欧拉筛）**的核心只有一句：每个合数只被它的最小质因子筛掉一次。分三点讲透：

  1. 当 i % primes[j] == 0 时，因为 primes 是从小到大枚举的，primes[j] 就是 i 的最小质因子，所以它同样是 i * primes[j] 的最小质因子；
  2. 当 i % primes[j] != 0 时，primes[j] 比 i 的所有质因子都小，因此它仍是 i * primes[j] 的最小质因子；
  3. 完备性：任取合数 x，设其最小质因子为 p，当 i 枚举到 x / p 时，内层循环枚举到 p 就会把 x 标记掉；而在此之前没有任何 i 会去筛 x。

于是每个合数恰好被标记一次，总复杂度 O(n)。埃氏筛是 O(n log log n)，差在同一个合数会被多个质数重复标记。

同余与逆元：a 在模 p 下可逆当且仅当 gcd(a,p)=1。p 为质数时由费马小定理 a^(p-1) ≡ 1 得 a^{-1} = a^(p-2)；一般情形用 exgcd 解 ax + py = 1。一次求 1..n 的全部逆元则用线性递推 inv[i] = (p - p/i) * inv[p % i] mod p，O(n) 算完。

exgcd 解 ax + by = gcd(a,b)：递归到 b = 0 返回 (g, 1, 0)，回溯时 x' = y, y' = x - (a/b)·y。裴蜀定理保证有解当且仅当 gcd(a,b) | c，通解为 x = x0 + k·(b/g)。

CRT：模数两两互质时，x ≡ a_i (mod m_i) 在模 M = ∏m_i 下唯一，用 exgcd 逐个合并；模数不互质要先判 a_i ≡ a_j (mod gcd(m_i,m_j))，再用 exCRT。

i = 6，primes = {2, 3, 5, ...}
j = 0：筛掉 12 = 2 * 6，此时 6 % 2 == 0 → break
12 的最小质因子是 2，它只会在 i = 6 这一步被筛一次

模板与实现

线性筛 + 欧拉函数

const int N = 100000005;
vector<int> primes;
vector<bool> comp(N);                    // 压位，1e8 也只占约 12 MB

void sieve(int n) {
    for (int i = 2; i <= n; ++i) {
        if (!comp[i]) primes.push_back(i);          // 没被标记的就是质数
        for (int p : primes) {
            if (1LL * p * i > n) break;             // 用 long long 判越界
            comp[p * i] = true;                     // 用最小质因子筛掉 p*i
            if (i % p == 0) break;                  // p 已是 i 的最小质因子，继续枚举会重复
        }
    }
}
const int N = 1000005;
int phi[N], primes[N], cnt;
bool comp[N];

void sievePhi(int n) {                   // 线性筛顺带求欧拉函数
    phi[1] = 1;
    for (int i = 2; i <= n; ++i) {
        if (!comp[i]) primes[cnt++] = i, phi[i] = i - 1;
        for (int j = 0; j < cnt && 1LL * primes[j] * i <= n; ++j) {
            int p = primes[j], x = p * i;
            comp[x] = true;
            phi[x] = (i % p == 0) ? phi[i] * p : phi[i] * (p - 1);
            if (i % p == 0) break;
        }
    }
}

快速幂、exgcd 与逆元

long long qpow(long long a, long long b, long long mod) {
    long long r = 1;
    for (a %= mod; b; b >>= 1, a = a * a % mod)
        if (b & 1) r = r * a % mod;
    return r;
}

// 解 ax + by = gcd(a,b)，返回 gcd，引用带回一组特解
long long exgcd(long long a, long long b, long long& x, long long& y) {
    if (!b) { x = 1, y = 0; return a; }
    long long g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

// 1..n 的全部逆元，要求 p 为质数且 n < p
inv[1] = 1;
for (int i = 2; i <= n; ++i)
    inv[i] = (p - p / i) * inv[p % i] % p;

复杂度与边界

  • 线性筛 O(n)、空间 O(n)；n ≤ 1e8 时 comp 必须压位（vector<bool> 或 bitset），普通 bool 数组会超内存。
  • 快速幂 O(log b)；mod ≤ 1e9 时 a*a 仍要 long long。
  • exgcd O(log min(a,b))，a / b * x 的中间乘积必须用 long long。
  • 逆元存在当且仅当 gcd(a,p)=1；p 为质数而 a 是 p 的倍数时无逆元，按题意特判。
  • 解出的 x 可能为负，统一 (x % b + b) % b 归一。

易错点

  • 线性筛少了 break：不判 i % p == 0，同一个合数会被多次标记，退化成埃氏筛。
  • 上界相乘溢出：p * i <= n 用 int 相乘会溢出，要写 1LL * p * i > n 再 break。
  • 负数取模：C++ 的 % 符号随被除数，exgcd、CRT 之后一律 (x % m + m) % m。
  • 把费马小定理用在合数模上：p 不是质数时 a^(p-2) 不是逆元，必须用 exgcd。
  • 忽略 gcd 判定：ax ≡ c (mod b) 有解当且仅当 gcd(a,b) | c。
  • 欧拉函数递推写反：i % p == 0 时是 phi[i] * p，否则是 phi[i] * (p - 1)。

例题拆解

线性筛素数（Luogu P3383）：输出第 k 小的质数，n 可达 1e8。跑一遍线性筛把质数按序存进数组，询问直接取下标 k-1；瓶颈在空间，comp 必须压位。

同余方程（Luogu P1082）：求 a x ≡ 1 (mod b) 的最小正整数解。等价于 ax + by = 1，题目保证 gcd(a,b) = 1，exgcd 求出特解 x0 后输出 (x0 % b + b) % b，为 0 则取 b。

乘法逆元（Luogu P3811）：求 1..n 每个数模 p 的逆元。令 inv[1] = 1，按 inv[i] = (p - p/i) * inv[p % i] % p 递推即可，O(n)；逐个快速幂是 O(n log p)，n 到 3e6 会超时。

自测清单

  • 能复述「每个合数只被最小质因子筛掉一次」的三点论证
  • 能手写 exgcd 并说明回溯时 x、y 如何交换
  • 知道逆元存在的条件，以及三种求法各自的适用场景
  • 能推导欧拉函数的线性筛递推
  • 能判断什么时候必须用 exCRT 而不能用 CRT
