数据结构 / 提高 / 第 7 节

树状数组

用 lowbit 把前缀和拆成 log n 段，改一个点只动 log n 个格子。 · 单点修改、前缀查询均 O(log n)；空间 O(n)

一句话理解

树状数组把前缀和切成 log n 个二进制块：每一块的长度是该下标最低位的 1 所代表的 2 的幂。修改时沿着 +lowbit 往上爬，查询时沿着 -lowbit 往下拆。

核心思想

普通前缀和数组 s[i] 支持 O(1) 查询，但改一个点要 O(n) 重建；树状数组在两者之间取了平衡：c[i] 只负责区间 (i - lowbit(i), i] 的和，也就是「以 i 结尾、长度等于 lowbit(i) 的一段」。

查询前缀 [1, x] 时，把 x 二进制里的每个 1 依次「减掉最低位」，恰好把 [1, x] 拆成不超过 log n 个互不重叠的块，累加这些 c 即可。修改 a[x] 时，所有管辖区间包含 x 的 c[i] 都要更新，它们正好是 x, x+lowbit(x), x+2·lowbit(x), …，同样只有 log n 个。

这个结构只依赖结合律与可差分（能用前缀相减还原区间）。加法、异或都满足，所以区间和、区间异或都能做；max 不满足可差分，因此树状数组不支持「区间最值 + 修改」，那要交给线段树或 ST 表。

两个高频变体要背熟：把树状数组建在差分数组上，就得到「区间加、单点查」；再用两棵树分别维护 b[i] 与 i·b[i]，就能做「区间加、区间和」。求逆序对则是把值当坐标，从右往左扫，统计已插入的、比当前值小的个数。

模板与实现

1. 单点修改 + 区间查询（最常用）

struct BIT {
    int n;
    vector<long long> c;
    BIT(int n = 0) : n(n), c(n + 2, 0) {}
    void add(int x, long long v) {          // 下标从 1 开始
        for (; x <= n; x += x & -x) c[x] += v;
    }
    long long sum(int x) {                  // 前缀 [1, x]
        long long s = 0;
        for (; x > 0; x -= x & -x) s += c[x];
        return s;
    }
    long long range(int l, int r) { return sum(r) - sum(l - 1); }
};

2. 区间加 + 单点查（差分树状数组）

// 建树：对差分数组 d[i] = a[i] - a[i-1] 做单点 add
void rangeAdd(BIT& t, int l, int r, long long v) {
    t.add(l, v);
    t.add(r + 1, -v);        // r + 1 可能等于 n + 1，数组要留够
}
long long pointQuery(BIT& t, int x) { return t.sum(x); }   // 差分的和即原值

3. 求逆序对

// 离散化后按值建树，从右往左扫：答案 += 已插入且值更小的个数
long long inv = 0;
for (int i = n; i >= 1; --i) {
    inv += bit.sum(a[i] - 1);
    bit.add(a[i], 1);
}

复杂度与边界

  • 修改、查询都是 O(log n)，常数远小于线段树；空间 O(n)。
  • n ≤ 1e6 时树状数组通常比线段树快一倍以上，1e7 级别也能勉强通过。
  • 值域很大（如 1e9）时必须先离散化，否则开不下数组。
  • 需要区间最值、区间乘、区间赋值时，直接换线段树。
  • 需要「历史最值」「区间第 k 小」等扩展时，一般用线段树或平衡树。

易错点

  • 下标从 0 开始：lowbit(0) = 0 会死循环，树状数组必须 1-indexed，原数组下标要 +1。
  • 数组开成 n：add(r + 1, -v) 在 r = n 时访问 n + 1，数组至少开到 n + 2。
  • 逆序对没离散化：值域 1e9 直接当下标会 RE。
  • 用树状数组求区间最值：max 不可差分，range(l, r) 的减法写法是错的。
  • 答案不用 long long：逆序对最多 n(n-1)/2，n = 1e5 时已经超出 int。
  • 多测不清空：c 数组和 n 都要按本次数据重置。

例题拆解

【模板】树状数组 1（Luogu P3374）：维护数列，支持单点加与区间求和。 转化：任意区间和都能拆成两个前缀和之差，这正是树状数组直接支持的形式。 做法：读入时逐个 add(a[i], a[i]) 建树，查询 [l, r] 输出 sum(r) - sum(l-1)。同一份结构也能改成差分用法（区间加、单点查），只需换掉建树时的含义。 复杂度：每次操作 O(log n)。

逆序对（Luogu P1908）：统计满足 i < j 且 a[i] > a[j] 的数对个数。 转化：对每个位置，数它右边有多少个比它小的数。 做法：离散化后从右往左扫，树状数组记录每个值出现次数，sum(a[i]-1) 就是右侧更小的个数；也可归并排序顺手统计。前者更好扩展到动态问题。 复杂度：O(n log n)。

自测清单

  • 能说出 c[i] 管辖的区间长度为什么是 lowbit(i)
  • 能手写 add 与 sum 且不越界
  • 会用差分树状数组实现区间加、单点查
  • 能解释为什么树状数组不能维护区间最值
  • 能独立完成逆序对的离散化与统计
