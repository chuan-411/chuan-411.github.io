图论 / 提高 / 第 2 节

最短路

非负边用堆优化 Dijkstra，有负边用 Bellman-Ford，多源小图用 Floyd。 · 堆优化 Dijkstra O((n+m) log m)；Bellman-Ford/SPFA 最坏 O(nm)；Floyd O(n³)

一句话理解

把「从源点走到某个点」看成一笔随时可以改写的账：一旦发现一条更便宜的中转路线，就把这个点的距离改小。所有最短路算法都在做同一件事——松弛，区别只在于按什么顺序松弛。

核心思想

记 dist[v] 为当前已知的源点到 v 的最短距离，松弛就是

dist[v] = min(dist[v], dist[u] + w(u,v))

它成立的理由是三角不等式：一条最短路总能拆成「到某个点的最短路 + 最后一条边」。要保证正确，做松弛时 dist[u] 必须已经是最终答案，而这取决于边权。

  • Dijkstra：每轮取出 dist 最小且尚未确定的点，它一定已经最优——因为边权非负，任何绕路都只会更长。一旦出现负权边，这个前提立刻崩塌。
  • Bellman-Ford：不挑顺序，把每条边松弛 n-1 轮。一条最短路最多 n-1 条边，第 i 轮结束时「边数不超过 i」的最短路已确定。它允许负权，也能判负环：若第 n 轮仍有边可以松弛，就存在从源点可达的负环。
  • SPFA 是 Bellman-Ford 的队列优化，只把被松弛过的点重新入队。随机图上很快，但最坏 O(nm)，网格图能把它卡死。
  • Floyd 换了个角度：f[k][i][j] 表示只允许用前 k 个点当中转时 i 到 j 的最短路，转移为 f[k][i][j] = min(f[k-1][i][j], f[k-1][i][k] + f[k-1][k][j])，第一维可以滚动掉。它求的是全源最短路，允许负权但不允许负环。
选择路线
边权全非负 ─┬─ 单源 ── 堆优化 Dijkstra
            └─ 全源且 n 小 ── Floyd
存在负权边 ─┬─ 单源 ── Bellman-Ford / SPFA
            └─ 判负环 ── 第 n 轮仍能松弛

模板与实现

三种写法按需取用：n 大且边权非负用第一段，需要负权或判负环用第二段，n 不超过几百求全源用第三段。

const long long INF = (long long)4e18;

struct Edge { int v; long long w; };
vector<vector<Edge>> g;                   // 1-indexed 邻接表

void dijkstra(int n, int s, vector<long long>& dist) {
    dist.assign(n + 1, INF);
    priority_queue<pair<long long,int>, vector<pair<long long,int>>,
                   greater<pair<long long,int>>> pq;   // 小根堆
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;        // 懒删除：过期状态直接跳过
        for (auto& e : g[u]) {
            if (d + e.w < dist[e.v]) {
                dist[e.v] = d + e.w;
                pq.push({dist[e.v], e.v});
            }
        }
    }
}
// 返回 true 表示存在从 s 可达的负环
bool spfa(int n, int s, vector<long long>& dist) {
    dist.assign(n + 1, INF);
    vector<int> cnt(n + 1, 0);            // 到该点的最短路边数
    vector<char> inq(n + 1, 0);
    queue<int> q;
    dist[s] = 0; q.push(s); inq[s] = 1;
    while (!q.empty()) {
        int u = q.front(); q.pop(); inq[u] = 0;
        for (auto& e : g[u]) {
            if (dist[u] + e.w < dist[e.v]) {
                dist[e.v] = dist[u] + e.w;
                cnt[e.v] = cnt[u] + 1;
                if (cnt[e.v] >= n) return true;   // 边数达到 n，必含负环
                if (!inq[e.v]) { q.push(e.v); inq[e.v] = 1; }
            }
        }
    }
    return false;
}
// f 已是邻接矩阵：f[i][i] = 0，无边为 INF
void floyd(int n, vector<vector<long long>>& f) {
    for (int k = 1; k <= n; ++k)          // 中转点必须在最外层
        for (int i = 1; i <= n; ++i) {
            if (f[i][k] == INF) continue;
            for (int j = 1; j <= n; ++j)
                f[i][j] = min(f[i][j], f[i][k] + f[k][j]);
        }
}

复杂度与边界

  • 堆优化 Dijkstra：O((n+m) log m)，空间 O(n+m)，是 n ≤ 1e5, m ≤ 2e5 的标准解。稠密图（m ≈ n²、n 只有几百）反倒用邻接矩阵的朴素 O(n²) 写法更省常数。
  • Bellman-Ford / SPFA：最坏 O(nm)，只在有负权或必须判负环时使用。
  • Floyd：O(n³) 时间、O(n²) 空间，n 超过 500 基本不可用。
  • INF 取 4e18 这类远离 long long 上限的值，避免 INF + w 溢出；判不可达用 d == INF。
  • 若题目不保证负环从源点可达（只问「图中是否存在负环」），把所有点预先入队，等价于建一个超级源点。

易错点

  • 负权边用 Dijkstra：贪心的前提是「绕路只会更长」，负边一出现结果就全错。
  • INF 溢出：用 INT_MAX 当 INF 再相加会变成负数，答案直接崩。
  • 无向图只加一条边：add(u,v,w) 之后还要反向加一次；重边按题目要求保留或取小。
  • 不判过期状态：不写 d > dist[u] 也能出正确解，但复杂度会退化。
  • 负环条件写错：数「入队次数 > n」在部分写法下会误判，数「最短路边数 ≥ n」更稳。
  • 多组数据不清空：g、dist、inq 全部要重置。

例题拆解

单源最短路径（标准版，Luogu P4779）：给定非负边权的有向图，求源点到每个点的最短距离。题意即模板，做法是堆优化 Dijkstra，复杂度 O((n+m) log m)。这组数据刻意能卡掉 SPFA，别抱侥幸心理；弱化版 P3371 规模小一档，同一份代码直接可过。

负环（Luogu P3385）：判断从 1 号点出发能否走到一个负环。做法：SPFA 维护 cnt[v] = cnt[u] + 1，一旦某个点的 cnt ≥ n，说明最短路里出现了环，而只可能由负环造成。最坏 O(nm)，本题点数只有几千，稳稳通过。

自测清单

  • 能说清 Dijkstra 为什么要求边权非负
  • 能说明 Bellman-Ford 为什么要跑 n-1 轮
  • 能不看模板写出堆优化 Dijkstra
  • 知道负环的两种判定方式及其差别
  • 拿到一道题能立刻判断该用哪种最短路算法
