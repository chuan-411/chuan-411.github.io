二分查找与二分答案

把「单调性」换成对数：查找是缩小范围，答案是缩小可行域。 · O(log n)，答案二分时乘上一次 check 的代价

一句话理解

只要问题具有「单调性」——某个条件在答案的一侧恒真、另一侧恒假——就可以每次砍掉一半的候选，把线性枚举压成对数级别。

核心思想

二分有两种常见形态，初学者最容易把它们混在一起：

  1. 二分查找：在已排好序的数组上找某个值（或第一个大于它的位置）。候选集合是数组下标。
  2. 二分答案：题目要求「最小的最大」「最大的最小」或「是否可行」，答案本身单调，于是二分答案 mid，用一次 check(mid) 判断 mid 是否可行。候选集合是答案的取值区间。

判断能不能二分答案，只问一句话：如果 mid 可行，那么比 mid 更宽松（或更严格）的一侧是不是全都可行？ 只要答案是「一段前缀可行 / 一段后缀可行」，就可以二分。

可行:  ✗ ✗ ✗ ✓ ✓ ✓ ✓
              ↑ 第一个可行的位置就是答案

模板

1. 查找第一个 >= x 的位置

int lower_bound_manual(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size();      // 答案范围 [l, r]
    while (l < r) {
        int mid = l + (r - l) / 2;     // 防止 l + r 溢出
        if (a[mid] >= x) r = mid;      // mid 可行，答案在 [l, mid]
        else l = mid + 1;              // mid 不可行，答案在 [mid+1, r]
    }
    return l;                          // 可能等于 a.size()，表示没有
}

2. 二分答案（最小化问题）

bool check(long long mid);             // 由题目实现

long long solve(long long lo, long long hi) {
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (check(mid)) hi = mid;      // mid 可行，尝试更小
        else lo = mid + 1;
    }
    return lo;
}

3. 浮点数二分

double solve(double lo, double hi) {
    for (int it = 0; it < 80; ++it) {  // 固定迭代次数，避免精度死循环
        double mid = (lo + hi) / 2;
        if (check(mid)) hi = mid;
        else lo = mid;
    }
    return lo;
}

复杂度与边界

  • 时间复杂度 O(log n)；二分答案的复杂度是 O(log V × check)，其中 V 是答案值域。
  • 区间必须是半开的写法才不容易错：统一用 [l, r) 或统一用 [l, r]，并且让 r 的初值包含答案。
  • mid 一律写成 l + (r - l) / 2，避免 l + r 在 int 上溢出。
  • 浮点二分不要写 while (r - l > 1e-8) 处理大值域，固定迭代 60~100 次更稳。

易错点

  • 没有单调性就硬二分：先证明「可行区间是一段连续前缀/后缀」，再动笔。
  • l、r 初值不对：r 必须是一个一定可行（或一定不可行）的位置，否则会漏掉边界答案。
  • 死循环：while (l < r) 里必须是 r = mid 和 l = mid + 1 搭配；如果写成 l = mid，就必须用 mid = (l + r + 1) / 2 向上取整。
  • 忘记 long long：答案值域到 1e18 时 mid 必须开 long long。
  • check 写得太慢：二分答案的总复杂度是 log × check，check 里套 O(n log n) 也可能超时，优先想 O(n) 的判断。

例题拆解

砍树（Luogu P1873）：给定树高数组，求锯片高度 h，使获得的木材不少于 m 时 h 最大。 单调性：h 越低，木材越多。于是二分 h，check(h) 为「锯掉 (a[i] - h) 的正部分之和是否 ≥ m」，取最后一个可行的 h。

A-B 数对（Luogu P1102）：统计满足 a[i] - a[j] = C 的对数。 思路：排序后对每个 a[i] 二分查找 a[i] - C 的左右端点，用 upper_bound - lower_bound 计数，复杂度 O(n log n)。

自测清单

  • 能不看模板写出「第一个 ≥ x」的下标
  • 能区分二分查找与二分答案的候选集合
  • 能证明一道题的答案具有单调性
  • 知道 l = mid 时为什么要向上取整
  • 能处理「答案不存在」的返回值
