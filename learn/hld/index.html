树链剖分

按重儿子把树切成链，让每条路径只落在 O(log n) 段连续区间上。 · 预处理 O(n)，路径操作 O(log² n)，子树操作 O(log n)

一句话理解

树上路径不好直接上数据结构，但如果把树「拍平」成一维数组，路径就变成若干段区间。树链剖分就是挑一种拍平方式——每条路径只被切成 O(log n) 段，然后交给线段树。

核心思想

dfs 序的性质：DFS 时按进入时刻给点编号 dfn，任意子树都恰好落在 [dfn[u], dfn[u]+siz[u]-1] 这个连续区间里。子树操作因此不需要剖分，麻烦的只有路径——它在 dfs 序里通常是散的。

重儿子与重链：siz 最大的儿子叫重儿子，其余叫轻儿子；重边连成的链叫重链，链头是「不是任何人的重儿子」的点。于是整棵树被划成若干条互不相交的重链。

为什么只有 O(log n) 段：每跳一次都是跨轻边，而轻儿子的子树不超过父节点的一半，所以子树大小不断减半，路径最多被切成 log n 段。这就是本算法复杂度的全部来源。

怎么剖：第一次 DFS 求 fa、dep、siz、son；第二次优先递归重儿子，同一条链上的点就拿到连续的 dfn。

路径操作怎么写：比较 dep[top[u]] 与 dep[top[v]]，把链头更深的整段 [dfn[top[u]], dfn[u]] 处理掉，再跳到 fa[top[u]]；两点同链时较深的那个就是 LCA，处理 [dfn[浅], dfn[深]] 即可。共 O(log n) 段，每段一次线段树操作。

        1
       / \
      2   3          siz: 2号子树最大 → 2 是重儿子
     / \   \         重链: 1-2-4-…
    4   5   6
    |
    7
  dfn 顺序（优先重儿子）：1, 2, 4, 7, 5, 3, 6
  重链 1-2-4-7 的 dfn 连续；轻儿子 5、3、6 各自另起一条链

模板与实现

const int N = 100005;
vector<int> g[N];
int fa[N], dep[N], siz[N], son[N];       // 父亲、深度、子树大小、重儿子
int top[N], dfn[N], rnk[N], timer;       // 链头、dfs 序、序对应点

void dfs1(int u, int f) {
    fa[u] = f, dep[u] = dep[f] + 1, siz[u] = 1;
    int best = 0;
    for (int v : g[u]) {
        if (v == f) continue;
        dfs1(v, u);
        siz[u] += siz[v];
        if (siz[v] > best) best = siz[v], son[u] = v;   // 重儿子 = siz 最大的儿子
    }
}

void dfs2(int u, int tp) {
    top[u] = tp, dfn[u] = ++timer, rnk[timer] = u;
    if (!son[u]) return;
    dfs2(son[u], tp);                    // 先走重儿子 ⇒ 重链 dfn 连续
    for (int v : g[u])
        if (v != fa[u] && v != son[u]) dfs2(v, v);       // 轻儿子另起一条链
}
// 路径上的点权加 w（线段树 seg 已按 dfn 建好）
void pathAdd(int u, int v, int w) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);       // 谁链头深，先处理谁
        seg.add(dfn[top[u]], dfn[u], w);                 // 一条重链上 dfn 连续
        u = fa[top[u]];                                  // 跳过整条链
    }
    if (dep[u] > dep[v]) swap(u, v);                     // 此时同链，u 就是 LCA
    seg.add(dfn[u], dfn[v], w);
}

// 子树加：直接就是一段连续区间
void subtreeAdd(int u, int w) {
    seg.add(dfn[u], dfn[u] + siz[u] - 1, w);
}

路径查询同理，把 seg.add 换成 seg.query 并累加即可；若要处理边权，把边权下放到深度较大的端点，最后一条路径查询时排除 LCA 那一段。

复杂度与边界

  • 预处理 O(n)；单次路径操作 O(log² n)；单次子树操作 O(log n)。
  • n, q ≤ 1e5 时约 3e7 次线段树操作，要快读并注意常数。
  • 递归深度等于树高：退化成链时 dfs1 会递归 1e5 层，C++ 默认栈可能不够，可改手写栈。
  • 多组数据要清空 g、son（不清会让 dfs2 走错）并把 timer 置 0。

易错点

  • dfs2 没先走重儿子：重链的 dfn 不连续，路径区间查询错位，而且不报错、只 WA。
  • 跳链时比较对象搞错：要比较 dep[top[u]] 而不是 dep[u]。
  • 同链后没取浅点做左端点：dep 更小的才是 LCA，区间应为 [dfn[浅], dfn[深]]；求边权时还要排除 LCA。
  • 子树右端点写成 dfn[u] + siz[u]：应为 dfn[u] + siz[u] - 1。
  • son 没初始化为 0：叶子残留上组数据的重儿子，dfs2 会访问不存在的点。
  • 点权与边权混用：边权必须下放到深度更大的端点，否则 LCA 的权值会重复或漏算。

例题拆解

树链剖分（Luogu P3384）：维护点权，支持路径加、路径求和、子树加、子树求和。路径操作靠「跳链 + 线段树区间操作」，子树操作直接利用 dfs 序的连续性；dfs1 求 siz 与 son，dfs2 按重儿子优先编号，按 rnk 建带懒标记的线段树。

树上操作（Luogu P3178）：支持单点加、子树加、查某点到根路径上的点权和。单点加是长度为 1 的区间加；「到根路径和」是路径查询取 v 为根的特例，跳链时不断累加 [dfn[top[u]], dfn[u]] 的和，最后补上同链那一段。

自测清单

  • 能证明「任意路径被切成 O(log n) 段」——从轻边导致子树减半讲起
  • 能默写 dfs1 求 siz、son 的过程
  • 能解释为什么 dfs2 必须先递归重儿子
  • 能不看模板写出路径修改的跳链循环
  • 知道边权转点权时最后一段要排除 LCA
