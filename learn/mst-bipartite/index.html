最小生成树与二分图

最小生成树靠切分性质贪心加边，二分图靠染色判定、增广路求匹配。 · Kruskal O(m log m)；Prim O(n²)；匈牙利 O(nm)

一句话理解

最小生成树是「用最便宜的一批边把所有点连成一片」，二分图是「把点分成两拨，让每条边都跨在两拨之间」。前者按边权从小到大贪心加边，后者靠染色判定、靠增广路求匹配。

核心思想

MST 的正确性来自切分性质：把点集任意切成 S 与 V-S，横跨这条割的边中权值最小的那条，一定属于某棵最小生成树。因为两边必须连通，总得有一条边跨过这条割，用它替换更贵的边不会更差。

  • Kruskal：所有边按权值升序，依次尝试加入，若两端已经在同一连通块（并查集判断）就丢弃。加满 n-1 条即得 MST，适合稀疏图。
  • Prim：从一个点出发，每次把「离当前生成树最近」的点拉进来，维护 dis[v] 为 v 到树的最短边长。适合稠密图与完全图，邻接矩阵写法 O(n²) 常数极小。

二分图：能被二染色（相邻点异色）的图就是二分图，等价于不含奇环。判定用 BFS/DFS 交替染色，遇到同色冲突即失败；图可能不连通，要对每个未染色的点各起一次。

最大匹配用匈牙利算法：不断寻找增广路（「未匹配—匹配—…—未匹配」的交替路），找到就把路上的匹配状态整体翻转，匹配数 +1。由 Berge 定理，找不到增广路时就是最大匹配。另有 König 定理：二分图的最小点覆盖等于最大匹配，最大独立集等于 n - 最大匹配。

增广：u1 — v2 — u2 — v3
     未配  已配  未配
翻转后 u1-v2、u2-v3，匹配数从 1 变 2

模板与实现

// Kruskal
struct Edge { int u, v; long long w; };

long long kruskal(int n, vector<Edge>& es) {   // 不连通返回 -1
    sort(es.begin(), es.end(),
         [](const Edge& a, const Edge& b) { return a.w < b.w; });
    vector<int> fa(n + 1);
    iota(fa.begin(), fa.end(), 0);
    function<int(int)> find = [&](int x) {
        return fa[x] == x ? x : fa[x] = find(fa[x]);
    };
    long long sum = 0; int cnt = 0;
    for (auto& e : es) {
        int ru = find(e.u), rv = find(e.v);
        if (ru == rv) continue;                 // 已连通，加了会成环
        fa[ru] = rv; sum += e.w;
        if (++cnt == n - 1) break;
    }
    return cnt == n - 1 ? sum : -1;
}
// Prim：邻接矩阵，适合完全图
long long prim(int n, vector<vector<long long>>& w) {
    const long long INF = (long long)4e18;
    vector<long long> dis(n + 1, INF);
    vector<char> vis(n + 1, 0);
    dis[1] = 0;
    long long sum = 0;
    for (int it = 1; it <= n; ++it) {
        int u = 0;
        for (int i = 1; i <= n; ++i)
            if (!vis[i] && (u == 0 || dis[i] < dis[u])) u = i;
        if (u == 0 || dis[u] == INF) return -1;  // 不连通
        vis[u] = 1; sum += dis[u];
        for (int v = 1; v <= n; ++v)
            if (!vis[v] && w[u][v] < dis[v]) dis[v] = w[u][v];
    }
    return sum;
}
// 匈牙利：返回最大匹配数
vector<vector<int>> adj;    // 左部 -> 右部
vector<int> matchR;         // 右部点匹配到的左部点，0 表示未匹配
vector<char> vis;

bool dfs(int u) {
    for (int v : adj[u]) {
        if (vis[v]) continue;
        vis[v] = 1;
        if (matchR[v] == 0 || dfs(matchR[v])) {
            matchR[v] = u;
            return true;
        }
    }
    return false;
}

int hungary(int nL, int nR) {
    matchR.assign(nR + 1, 0);
    int res = 0;
    for (int u = 1; u <= nL; ++u) {
        vis.assign(nR + 1, 0);      // 每轮增广都要重新清空
        if (dfs(u)) ++res;
    }
    return res;
}

复杂度与边界

  • Kruskal：O(m log m)，代价几乎全在排序，m 到 1e6 仍可行。
  • Prim：邻接矩阵 O(n²)；完全图（如 P1546，n ≤ 100）时它比 O(n² log n) 的 Kruskal 更省事。堆优化版为 O(m log n)。
  • 匈牙利：O(nm)，二分图规模到 1e3 量级可以接受，再大就要换 Dinic。
  • 边权和用 long long；n = 1 时 MST 权值为 0，注意输出。
  • 二分图判定对每个连通块都要起一次，孤立点单独成块，不影响结论。

易错点

  • Kruskal 忘排序：贪心的前提就是按边权升序，顺序错了结果必错。
  • 成环边没被判掉：必须用并查集判连通性，不能只看「点是否访问过」。
  • 不判连通：cnt < n-1 说明 MST 不存在，即使题目保证连通也别省这一步。
  • 自环没跳过：自环永远不该进 MST，加边前判 u == v 更保险。
  • 只从一个点染色：图不连通时会漏判，必须遍历所有未染色点。
  • 匈牙利 vis 不清空：每轮增广都要重新标记，否则匹配数偏小。

例题拆解

最小生成树（Luogu P3366）：给定带权无向图，求 MST 的边权和，不连通输出 orz。做法：Kruskal 排序加并查集，凑满 n-1 条边即停，复杂度 O(m log m)。这是 MST 的模板题，重点是把「不连通」的判定写对。

二分图最大匹配（Luogu P3386）：左右各 n、m 个点，e 条边，求最大匹配数。做法：以每个左部点为起点尝试增广，vis 保证本轮每个右部点只被访问一次，总复杂度 O(nm)。答案就是匹配数，注意读入的边可能重复，多重边不影响正确性。

自测清单

  • 能说出切分性质，并用它解释 Kruskal 为什么正确
  • 知道什么图该用 Kruskal、什么图该用 Prim
  • 能证明二分图等价于不含奇环
  • 能手写匈牙利，并解释「找不到增广路就最优」
  • 记得 König 定理的两个推论
