前缀和与差分

前缀和把「一段」压成「两点相减」，差分把「一段修改」压成「两个端点」。 · 预处理 O(n)，单次区间查询/区间修改 O(1)，还原 O(n)

一句话理解

前缀和像记账：不每次重算这一段的总和，而是记下「从开头到这里的累计」，任意一段就是两个累计值相减。差分反过来，它只记录「哪里开始变、哪里变回去」，最后累计一次就还原出整个数组。

核心思想

前缀和：令 pre[i] = a[1] + a[2] + … + a[i]，则区间和 sum(l, r) = pre[r] - pre[l-1]，一次查询 O(1)。前提是运算可减——加法、异或、模意义下的加法都行；max、gcd 这类不可减的运算不能用前缀和求任意区间，只能改用 ST 表或线段树。

前缀和还能把「区间问题」转成「两点问题」。最大子段和就是典型：sum(l, r) = pre[r] - pre[l-1]，固定右端点 r 时只需让 pre[l-1] 尽量小，于是扫一遍并维护「历史最小前缀」即可，O(n)。

二维前缀和用容斥：pre[i][j] 表示左上角 (1,1) 到 (i,j) 的矩形和， S = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]，注意最后一项是加。

差分是前缀和的逆运算：令 d[i] = a[i] - a[i-1]，则 a 是 d 的前缀和。对区间 [l, r] 整体加 v，只需 d[l] += v、d[r+1] -= v，因为中间的差分值不受影响。做完全部修改后，对 d 求一次前缀和就还原出最终数组。这正好适合「多次区间修改、最后一次统一查询」的题型，把 O(nq) 降到 O(n + q)。

二维差分同理：给矩形 (x1,y1)-(x2,y2) 加 v，在四个角打标记 +v, -v, -v, +v，最后做二维前缀和还原。二维前缀和与二维差分互为逆运算，容斥的符号顺序要背熟。

a:      3  1  4  1  5
pre:    3  4  8  9 14      pre[i] = pre[i-1] + a[i]
区间[2,4] = pre[4] - pre[1] = 9 - 3 = 6   (1+4+1)

d:      3 -2  3 -3  4      d[i] = a[i] - a[i-1]
对 [2,4] 加 10：d[2] += 10, d[5] -= 10
d':     3  8  3 -3 -6  → 前缀和还原 → 3 11 14 11 5

模板与实现

// 1. 一维前缀和：1-indexed，pre[0] = 0
vector<long long> pre(n + 1, 0);
for (int i = 1; i <= n; ++i) pre[i] = pre[i - 1] + a[i];
auto rangeSum = [&](int l, int r) { return pre[r] - pre[l - 1]; };

// 2. 二维前缀和：容斥，注意最后一项是 +
for (int i = 1; i <= n; ++i)
    for (int j = 1; j <= m; ++j)
        pre[i][j] = a[i][j] + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1];

auto rectSum = [&](int x1, int y1, int x2, int y2) {
    return pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
};

// 3. 一维差分：区间加，最后前缀和还原
vector<long long> d(n + 2, 0);              // 多开一位，防 r + 1 越界
auto addRange = [&](int l, int r, long long v) {
    d[l] += v;
    d[r + 1] -= v;
};
// 还原
long long cur = 0;
for (int i = 1; i <= n; ++i) { cur += d[i]; a[i] = cur; }

二维差分只多四行，思路一致：(x1,y1)+v、(x1,y2+1)-v、(x2+1,y1)-v、(x2+1,y2+1)+v。

复杂度与边界

  • 预处理 O(n)（二维 O(nm)），单次查询或修改 O(1)，还原 O(n)。
  • 前缀和数组必须开 long long：n = 1e5、aᵢ ≤ 1e9 时总和可达 1e14。
  • 差分数组开到 n + 2：r + 1 在 r = n 时正好是 n + 1。
  • 二维数组优先用一维展平（id = i * (m+1) + j）或 vector<vector<>>，n·m ≤ 1e7 时小心内存。
  • 只适合可减运算；求区间最值请换 ST 表 / 线段树。

易错点

  • 下标混用：前缀和天然要 1-indexed（pre[0]=0 代表空前缀），和 0-indexed 的输入混写会整体错位。
  • 差分忘记还原：打完标记只得到 d，必须再做一次前缀和才是最终值。
  • d[r+1] 越界：数组只开 n 个、却写 d[r+1]，r = n 时越界。
  • 二维容斥符号写错：pre[x1-1][y1-1] 前是加号，漏掉会让角上的重叠区域被多减。
  • 最大值初始化成 0：最大子段和可能全为负数，答案初值要设 -INF。
  • 用前缀和求区间 max：减法对 max 不成立，pre[r] - pre[l-1] 与最值毫无关系。

例题拆解

最大子段和（Luogu P1115）

题意：给定长度为 n 的序列，求一段非空连续子段的和的最大值，n ≤ 2e5，元素可正可负。

转化：sum(l, r) = pre[r] - pre[l-1]。固定 r 时想让结果最大，就要让 pre[l-1] 尽量小，即「r 之前出现过的最小前缀和」。

做法：边扫边维护 minPre（初值为 pre[0] = 0，对应 l = 1），每步用 pre[r] - minPre 更新答案，再把 pre[r] 计入 minPre。注意必须先更新答案再更新 minPre，否则会出现空段。这就是 Kadane 算法的前缀和版本。

复杂度：时间 O(n)，空间 O(1)（滚动维护）。

语文成绩（Luogu P2367）

题意：n 个学生的成绩，p 次操作，每次给区间 [x, y] 内每人加 z（z 可为负），最后输出最低分。

转化：p 次区间修改、只在最后查询一次，正是差分的适用场景；若每次修改都遍历区间，复杂度 O(np)。

做法：对每次操作做 d[x] += z、d[y+1] -= z；全部操作结束后从前往后做前缀和还原成绩，同时取最小值。

复杂度：时间 O(n + p)，空间 O(n)。

自测清单

  • 能闭眼写出二维前缀和的容斥式并说清每一项的符号
  • 能解释差分为什么只需要改两个端点
  • 知道前缀和只对可减运算成立
  • 能用前缀和 + 最小前缀写出最大子段和
  • 清楚差分数组为什么开到 n + 2
