计算几何基础

一切从叉积出发：定方向、判左右、算面积，再谈凸包与分治。 · 凸包 O(n log n)，最近点对 O(n log n)

一句话理解

计算几何的原子是叉积：它给出两个向量的相对朝向，于是「点在直线哪一侧」「三点是否左转」「多边形面积」都能一次算完。搞清楚叉积的符号，剩下都是排序和分治。

核心思想

向量与两种积：设 a = (x1,y1)、b = (x2,y2)。

  • 点积 a·b = x1x2 + y1y2 = |a||b|cos θ：判断垂直与夹角锐钝。
  • 叉积 a×b = x1y2 - y1x2 = |a||b|sin θ：叉积为正表示 b 在 a 的逆时针方向（左侧），为负表示右侧，为 0 表示共线。

叉积的绝对值等于以 a、b 为邻边的平行四边形面积，所以多边形面积就是按顶点顺序「叉积求和、取绝对值、除以 2」（鞋带公式）。判「线段 ab 与 cd 是否相交」用跨立实验：cross(b-a, c-a) 与 cross(b-a, d-a) 异号，且反向也异号，才真正穿过；共线时单独判是否落在线段上。

凸包：包含所有点的最小凸多边形。Andrew 算法把点按 (x,y) 排序，先从左到右扫出下凸壳、再从右到左扫出上凸壳，用叉积判「新点是否让最后一个拐点右转（或共线）」，是就弹栈。整个过程 O(n log n)，瓶颈在排序。

    ／‾‾‾‾＼
   ／       ＼        单调栈维护当前壳：
  ／  ●  ●   ＼       若 cross(栈顶-次顶, p-次顶) <= 0
  ＼         ／       说明要右转/共线 → 弹掉栈顶
    ＼____／
     下凸壳

最近点对：按 x 排序后分治，左右两半各自求最小值 d，再检查跨越中线的「带状区域」。关键剪枝是带宽只有 2d，且带内的点按 y 排序后每个点最多与后面 7 个点比较——因为同一侧 d×d 的小方块里最多容纳有限个点。于是总复杂度 O(n log n)。

模板与实现

基本运算与凸包

struct Point {
    double x, y;
    Point operator+(const Point& o) const { return {x + o.x, y + o.y}; }
    Point operator-(const Point& o) const { return {x - o.x, y - o.y}; }
    bool operator<(const Point& o) const {       // 先按 x 再按 y
        return x != o.x ? x < o.x : y < o.y;
    }
};

double cross(const Point& a, const Point& b) {   // 叉积：>0 表示左转
    return a.x * b.y - a.y * b.x;
}
double dot(const Point& a, const Point& b) {
    return a.x * b.x + a.y * b.y;
}
double dist(const Point& a, const Point& b) {
    return hypot(a.x - b.x, a.y - b.y);          // sqrt(dx*dx+dy*dy)
}

vector<Point> convexHull(vector<Point> p) {      // 返回逆时针凸包，不含重复起点
    sort(p.begin(), p.end());
    int n = (int)p.size(), k = 0;
    if (n < 3) return p;
    vector<Point> h(2 * n);
    for (int i = 0; i < n; ++i) {                // 下凸壳
        while (k >= 2 && cross(h[k - 1] - h[k - 2], p[i] - h[k - 2]) <= 0) --k;
        h[k++] = p[i];
    }
    for (int i = n - 2, t = k + 1; i >= 0; --i) { // 上凸壳
        while (k >= t && cross(h[k - 1] - h[k - 2], p[i] - h[k - 2]) <= 0) --k;
        h[k++] = p[i];
    }
    h.resize(k - 1);                              // 末尾与起点重合，去掉
    return h;
}

若只想要严格凸包，上面的 <= 0 会删掉共线点；若要保留边上的点，改成 < 0。

平面最近点对（分治）

double closest(vector<Point>& p, int l, int r) {  // p 已按 x 排序
    if (r - l + 1 <= 3) {                         // 小规模直接暴力
        double d = 1e100;
        for (int i = l; i <= r; ++i)
            for (int j = i + 1; j <= r; ++j) d = min(d, dist(p[i], p[j]));
        return d;
    }
    int mid = (l + r) >> 1;
    double mx = p[mid].x;
    double d = min(closest(p, l, mid), closest(p, mid + 1, r));
    vector<Point> strip;                          // 只有 x 方向距离小于 d 的点才可能更新答案
    for (int i = l; i <= r; ++i)
        if (fabs(p[i].x - mx) < d) strip.push_back(p[i]);
    sort(strip.begin(), strip.end(),
         [](const Point& a, const Point& b) { return a.y < b.y; });
    for (int i = 0; i < (int)strip.size(); ++i)
        for (int j = i + 1; j < (int)strip.size() && strip[j].y - strip[i].y < d; ++j)
            d = min(d, dist(strip[i], strip[j]));
    return d;
}

带内每个点只需与后面少数几个点比较，实际运行接近线性；把「按 y 归并」写进递归可以省掉每次排序，得到严格的 O(n log n)。

复杂度与边界

  • 凸包 O(n log n)，空间 O(n)；n 到 1e5 完全够用。
  • 最近点对：每次递归对带内点排序是 O(n log² n)，n 到 2e5 仍可通过；改成归并则 O(n log n)。
  • 凸包退化：所有点共线时只剩两个顶点，h.resize(k-1) 后要单独处理，输出按题目要求。
  • 精度：判共线别写 cross == 0，改用 fabs(cross) < 1e-9；坐标是整数时优先用 long long 叉积。
  • 鞋带公式记得取绝对值、除以 2，逆时针与顺时针符号相反。

易错点

  • 叉积方向记反：cross(b-a, c-a) > 0 表示 c 在 ab 左侧，符号写反会让整个凸包反向。
  • 用 == 比较浮点：判断共线、重合都要带 eps，否则单调栈会弹出错误的点。
  • 凸包没去重：输入有重复点时会出现零长度边，叉积恒为 0，弹栈逻辑会把合法顶点也弹掉。
  • 共线点的取舍没想清楚：保留还是删除取决于题目，别混用。
  • 最近点对漏了跨中线检查：只在左右两半内部递归，会漏掉一左一右的最优解。
  • 最近点对没有 y 方向剪枝：带内两两比较会退化成 O(n²)，必须有 strip[j].y - strip[i].y < d 的终止条件。
  • hypot 参数顺序：hypot(dx, dy) 是斜边，只传一个参数会算错。

例题拆解

二维凸包（Luogu P2742）：给 n 个点，求凸包周长。周长即凸包上相邻顶点距离之和，核心是求出顶点序列：Andrew 单调链排序后扫下凸壳、再扫上凸壳，cross <= 0 时弹栈，最后累加相邻点距离并补上末点到首点的距离，O(n log n)；点数小于 3 或全部共线时按退化情形输出。

平面最近点对（加强版）（Luogu P1429）：求 n 个点中最近两点的距离。两两比较是 O(n²)，n 到 2e5 不可行；按 x 排序后二分，递归求两半的最小值 d，把 |x - mid.x| < d 的点收集起来按 y 排序，只在 y 差小于 d 的范围内比较，输出保留 4 位小数。

自测清单

  • 能说出叉积的符号对应哪一侧，并写出鞋带公式
  • 能用跨立实验判断两线段是否相交，并处理共线情形
  • 能默写 Andrew 凸包的下凸壳部分
  • 知道凸包什么时候会退化，退化时怎么输出
  • 能解释最近点对为什么只需比较带内少数几个点
