组合计数与容斥

先分类、再分步，最后把重复数的部分减回去。 · 阶乘预处理 O(n) 后单次 O(1)；Lucas O(p + log_p n)

一句话理解

计数题的答案很少能「直接数出来」：先按互斥的类分开（加法原理），再按独立的步骤相乘（乘法原理），最后把重复数的部分减回去（容斥）。组合数是这一切的原子。

核心思想

两个基本原理：互斥的类之间用加法，独立的步骤之间用乘法。绝大多数组合计数都是把问题翻译成「先选出哪几个，再决定怎么排」。

组合数：C(n,m) 表示从 n 个不同元素里取 m 个的方案数，满足 C(n,m) = C(n-1,m) + C(n-1,m-1)——最后一个元素选或不选。这条递推就是杨辉三角，也是 O(nm) 打表的来源。要单次 O(1) 查询，就预处理阶乘与阶乘逆元：C(n,m) = fac[n]·ifac[m]·ifac[n-m]，前提是模数 p 为质数且 n < p，否则 fac[n] 里含 p 的因子，逆元不存在。

Lucas 定理：当 n、m 远大于质数 p 时，把 n、m 写成 p 进制，逐位求组合数再相乘：

C(n, m) ≡ ∏ C(n_i, m_i)  (mod p)，n_i、m_i 是 p 进制下的第 i 位

它的含义是「模 p 下组合数按位独立」，于是 O(p) 预处理后每次只要 O(log_p n)。

容斥原理：|A_1 ∪ … ∪ A_k| = Σ|A_i| - Σ|A_i ∩ A_j| + …。用法是把「至少满足一个坏条件」写成并集，让每一项只依赖「强制若干条件成立后剩下多少自由选择」，这样每一项都能 O(1) 算出来。

卡特兰数：Catalan(n) = C(2n,n) / (n+1)，也满足 h[n] = Σ h[i]·h[n-1-i]。它数的是「任意前缀中某种东西不超过另一种」的序列：n 个元素的出栈序列、n 对括号的合法匹配、凸 n+2 边形的三角剖分。

容斥把「并集」拆成「交集」的和：
|A∪B| = |A| + |B| - |A∩B|
每一项都是「先强制若干条件，剩下的随便选」

模板与实现

预处理阶乘求组合数

const int N = 1000005;
long long fac[N], ifac[N];

long long qpow(long long a, long long b, long long p) {
    long long r = 1;
    for (a %= p; b; b >>= 1, a = a * a % p)
        if (b & 1) r = r * a % p;
    return r;
}

void init(int n, long long p) {          // 要求 p 为质数且 n < p
    fac[0] = 1;
    for (int i = 1; i <= n; ++i) fac[i] = fac[i - 1] * i % p;
    ifac[n] = qpow(fac[n], p - 2, p);     // 费马小定理
    for (int i = n; i >= 1; --i) ifac[i - 1] = ifac[i] * i % p;
}

long long C(int n, int m, long long p) {
    if (m < 0 || m > n) return 0;         // 边界必须先判
    return fac[n] * ifac[m] % p * ifac[n - m] % p;
}

Lucas 定理

long long lucas(long long n, long long m, long long p) {
    if (m == 0) return 1;                 // 递归出口：C(n,0) = 1
    return C(n % p, m % p, p) * lucas(n / p, m / p, p) % p;
}

容斥

// 求 1..n 中与 m 互质的数的个数：用容斥减去含 m 的质因子的数
long long coprimeCount(long long n, long long m) {
    vector<long long> pf;
    for (long long d = 2; d * d <= m; ++d)
        if (m % d == 0) {
            pf.push_back(d);
            while (m % d == 0) m /= d;
        }
    if (m > 1) pf.push_back(m);
    int k = (int)pf.size();
    long long bad = 0;
    for (int S = 1; S < (1 << k); ++S) {  // 枚举「强制成立」的条件子集
        long long prod = 1;
        int bits = 0;
        for (int i = 0; i < k; ++i)
            if (S >> i & 1) prod *= pf[i], ++bits;
        bad += (bits & 1 ? 1 : -1) * (n / prod);   // 奇加偶减
    }
    return n - bad;
}

复杂度与边界

  • 阶乘预处理 O(n)，单次组合数 O(1)，空间两个长度 n 的数组。
  • 杨辉三角递推 O(nm)，适合 n,m ≤ 2000，且不要求模数是质数。
  • Lucas 预处理 O(p)、单次 O(log_p n)；p 很大（如 1e9+7）时没法预处理，只能回到阶乘 + 逆元。
  • 卡特兰数增长极快，n > 30 就必须取模或上高精度。
  • 容斥复杂度 O(2^k · k)，k > 20 时要换 DP 或 meet-in-the-middle。

易错点

  • 模数不是质数还用阶乘逆元：p 为合数时 fac[n] 可能不与 p 互质，逆元不存在，应改用递推或 exLucas。
  • n ≥ p 时硬套阶乘公式：此时 n! ≡ 0 (mod p)，必须走 Lucas。
  • 卡特兰公式的除法没换逆元：除以 n+1 在模意义下要乘逆元，且要求 p 与 n+1 互质。
  • 容斥符号写反：奇数个条件取正、偶数个取负，建议统一写成 bits & 1 ? +1 : -1。
  • 1 << k 溢出：k 接近 31 时要用 1LL << k。
  • 组合数边界漏判：m < 0 或 m > n 必须返回 0，递归版本同样要判。

例题拆解

组合数问题（Luogu P2822）：给定 k，多次询问 (n,m)，求有多少对 (i,j) 满足 1 ≤ i ≤ n、1 ≤ j ≤ min(i,m) 且 C(i,j) 是 k 的倍数。只关心 C(i,j) mod k 是否为 0，于是在杨辉三角上 O(nm) 递推，再对 0/1 矩阵做二维前缀和，每次询问 O(1)。

Lucas 定理（Luogu P3807）：求 C(n+m, n) mod p，p 是质数而 n、m 远大于 p。直接算阶乘会因 n ≥ p 全变成 0，必须按 p 进制拆位：预处理 0..p-1 的阶乘与逆元，调用 lucas(n+m, n, p) 递归逐位相乘，O(p + log_p n)。

栈（Luogu P1044）：1..n 依次入栈，求不同出栈序列个数。任意时刻已出栈元素都不超过已入栈个数，这正是卡特兰数；n ≤ 18，直接按 h[0] = 1, h[i] = Σ h[j]·h[i-1-j] 递推，O(n²)，无需取模。

自测清单

  • 能用「最后一个元素选不选」推出 C(n,m) 的递推式
  • 说清阶乘逆元法的三个前提（p 为质数、n < p、预处理范围）
  • 能写出 Lucas 的递归式并解释「按位独立」
  • 会把一道「至少一个」的题写成容斥并确定每项符号
  • 能认出卡特兰数的常见包装（出栈、括号、三角剖分）
