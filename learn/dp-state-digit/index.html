状压 DP 与数位 DP

状压把集合压进二进制位，数位 DP 从高位逐位决策并记忆化。 · 状压 O(n·S²)；数位 DP O(位数 × 状态数 × 10)

一句话理解

状压 DP 是把「哪些元素已经被选」这类集合状态写成一个整数的二进制位，于是集合运算变成 &、|、^；数位 DP 是把「不超过 x 的满足条件的数有多少个」按十进制位拆开，一位一位地填，并记住当前是否还贴着上界。

核心思想

状压的适用信号很明确：状态是子集，且规模 n ≤ 20 左右。f[S] 表示已选集合为 S 时的最优值，转移枚举下一个加入的元素。棋盘类题目则把每一行的放置情况压成一个 m 位二进制数。

以「互不侵犯」为例：一行内不能有相邻的国王，所以只有 s & (s << 1) == 0 的状态合法；上下两行既不能同列相邻，也不能斜着相邻，于是要同时满足 s & t == 0、(s << 1) & t == 0、s & (t << 1) == 0。先把所有合法行状态预处理出来，状态数能从 2^m 降到几十个，复杂度立刻变得可接受。

数位 DP 的状态是 dfs(pos, 其它约束, limit, lead)：pos 是当前填到第几位，limit 表示前面是否一直贴着上界（贴住时这一位最多只能填到 x 的对应位），lead 表示是否仍处于前导零。只有在 !limit && !lead 时才能记忆化，因为贴着上界的路径是「一次性」的，换个上界就失效。

求区间 [a, b] 的答案统一用 solve(b) - solve(a-1)，这是数位 DP 最常见的调用方式。

x = 2 5 7，填到第 2 位时：
  前一位填了 2（贴住上界）→ 这一位只能填 0..5，limit 仍为真
  前一位填了 1（已小于）  → 这一位可填 0..9，limit 为假

模板与实现

// 状压：n×n 棋盘放 k 个国王，八邻域互不攻击，求方案数
int n, K;
vector<int> ok;                 // 合法行状态
vector<int> cnt1;               // 每个状态中 1 的个数
long long f[10][1 << 9][90];    // f[行][状态下标][已放个数]

for (int s = 0; s < (1 << n); ++s)          // 行内不能有相邻 1
    if (!(s & (s << 1))) { ok.push_back(s); cnt1.push_back(__builtin_popcount(s)); }

int S = ok.size();
for (int i = 0; i < S; ++i)
    if (cnt1[i] <= K) f[1][i][cnt1[i]] = 1;

for (int row = 2; row <= n; ++row)
    for (int i = 0; i < S; ++i)             // 上一行
        for (int j = 0; j < S; ++j) {       // 本行
            int a = ok[i], b = ok[j];
            if (a & b) continue;            // 同列相邻
            if ((a << 1) & b) continue;     // 一条斜线
            if (a & (b << 1)) continue;     // 另一条斜线
            for (int c = 0; c + cnt1[j] <= K; ++c)
                f[row][j][c + cnt1[j]] += f[row - 1][i][c];
        }
// 答案：Σ f[n][j][K]
// 数位 DP：统计 [0, x] 中 digit 出现的次数
long long f[20][20];        // f[pos][已出现次数]，每组 digit 前要重置为 -1
int a[20], len;             // a[1..len] 为 x 的各位（低位在前）

long long dfs(int pos, int cnt, bool limit, bool lead, int digit) {
    if (pos == 0) return cnt;
    if (!limit && !lead && f[pos][cnt] != -1) return f[pos][cnt];
    int up = limit ? a[pos] : 9;
    long long res = 0;
    for (int d = 0; d <= up; ++d) {
        bool nlimit = limit && (d == up);
        if (lead && d == 0) res += dfs(pos - 1, 0, nlimit, true, digit);
        else res += dfs(pos - 1, cnt + (d == digit), nlimit, false, digit);
    }
    if (!limit && !lead) f[pos][cnt] = res;
    return res;
}

复杂度与边界

  • 状压：朴素枚举状态对是 O(n·4^m)；预处理合法状态后为 O(n·S²)，m = 9 时 S 只有几十个。
  • m 到 15 以上基本要换轮廓线 DP（插头 DP），否则状态数扛不住。
  • 数位 DP：O(位数 × 状态数 × 10)，x ≤ 1e18 时位数只有 19，非常宽松。
  • 记忆化数组按约束维度开；多组数据要么清空，要么把「第几组」也做成一维。
  • 计数结果用 long long：P2602 的答案量级到 1e13，int 存不下。

易错点

  • 只判行内相邻：棋盘类题目还要判上下与两条斜线，漏一个条件答案直接翻倍。
  • 不筛合法状态：直接用 2^m 枚举状态对，m = 12 就会超时。
  • 数位 DP 忘了 lead：前导零被当成真实的 0 统计，答案偏大。
  • 对 limit 分支也记忆化：贴着上界的结果依赖具体上界，存下来下次就错。
  • a - 1 下溢：a = 0 时 solve(-1) 必须特判返回 0。
  • 多组数据不清空：f 里残留上一组的结果，是最难查的错误。

例题拆解

互不侵犯（Luogu P1896）：n × n 棋盘放 k 个国王，任意两个不能相邻（含斜向），求方案数。做法：用 s & (s << 1) == 0 筛出行内合法状态，行间用三条与运算判冲突，f[row][j][cnt] 逐行累加。复杂度 O(n·S²·k)。玉米田 P1879 是同一模型的「有障碍格 + 求方案数」版本，把不能种的列在状态里屏蔽掉即可。

数字计数（Luogu P2602）：给定 a, b，统计 [a, b] 中数码 0..9 各出现多少次。做法：对每个数码各跑一次数位 DP，cnt 记录它已出现的次数，lead 屏蔽前导零，答案用 solve(b) - solve(a-1)。复杂度 O(10 × 位数 × 状态数)。

自测清单

  • 能判断一道题的状态该不该用状压
  • 能写出「行内合法、行间合法」的三条判据
  • 知道数位 DP 为什么通常写成记忆化搜索
  • 能解释 limit 与 lead 各自的作用
  • 会写 solve(b) - solve(a-1) 并处理 a = 0
