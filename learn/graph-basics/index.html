图论 / 提高 / 第 1 节

图论基础与遍历

先把图存成表，再用 DFS/BFS 沿着边走完它能到的每一个点。 · 存图 O(n + m)，一次 DFS/BFS 遍历 O(n + m)

一句话理解

图就是「点」和「边」组成的网络，遍历就是从一个点出发，沿着边走遍所有能到达的点。DFS 是一条路走到黑再回头，BFS 是一圈一圈往外扩。

核心思想

存图先要选对容器。邻接矩阵 g[u][v] 查询 O(1) 但要 O(n²) 空间，只在稠密图或 n ≤ 1000 时用；邻接表 vector<int> g[N] 是最常用的写法，空间 O(n + m)、遍历一个点的邻居 O(度数)；链式前向星用数组模拟链表，常数更小、内存更省，适合边数上百万的题。无向图的一条边要存两次，所以边数组要开 2m。

DFS 用递归或显式栈，沿一条路径走到底再回溯。它天然适合回答「连通性、连通块个数、有没有环、能不能到达」这类问题，也是 Tarjan、欧拉路、拓扑排序（DFS 逆后序）的基础。代价是深度可能达到 n，n 到 1e5 以上时递归有爆栈风险，可以开大栈空间或改成显式栈。

BFS 用队列按层扩展，首次访问一个点时的层数就是它到起点的最少边数，所以无权图最短路、多源扩散、网格步数都用它。变体是把队列换成双端队列的 0-1 BFS（边权只有 0 和 1），或者按距离分层的多源 BFS。

几个必须掌握的小结论：对每个未访问点发起一次 DFS 就能数出连通块个数；BFS 交替染色可以判定二分图（相邻点必须异色，冲突即失败）；不断取出入度为 0 的点得到拓扑序，若取出的点少于 n 则图中有环；把边反向建图，就能回答「哪些点能到达 x」，这正是 P3916 的核心技巧。

模板与实现

1. 邻接表 + DFS / BFS

const int N = 1e5 + 5;
vector<int> g[N];
bool vis[N];

void dfs(int u) {
    vis[u] = true;
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}

void bfs(int s) {
    queue<int> q;
    q.push(s);
    vis[s] = true;                 // 入队时立刻标记，别等出队
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : g[u])
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
    }
}

2. 链式前向星（边数很大时用）

int head[N], nxt[M << 1], to[M << 1], ecnt = 1;
void addEdge(int u, int v) {
    to[++ecnt] = v;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
}
// 遍历：for (int e = head[u]; e; e = nxt[e]) { int v = to[e]; ... }

3. 拓扑排序（Kahn）

int deg[N];
queue<int> q;
for (int i = 1; i <= n; ++i) if (!deg[i]) q.push(i);
int cnt = 0;
while (!q.empty()) {
    int u = q.front(); q.pop(); ++cnt;
    for (int v : g[u]) if (--deg[v] == 0) q.push(v);
}
// cnt < n 说明存在环

复杂度与边界

  • 邻接表存图 O(n + m)，遍历每条边两次（无向图），整体 O(n + m)。
  • 邻接矩阵空间 O(n²)，n > 5000 基本就开不下。
  • 递归 DFS 深度可达 n，1e5 以上建议显式栈或改 BFS。
  • 边权全为 1 时 BFS 求最短路是 O(n + m)；有正权时换 Dijkstra。
  • 多测务必按实际点数、边数清空，不要 memset 整个数组。

易错点

  • 无向图边数组只开 m：每条边存两次，必须开 2m。
  • vis 在出队时才标记：同一个点会被重复入队，复杂度退化成指数级。
  • 递归 DFS 爆栈：链状图深度等于 n，本地能过、评测机上 RE。
  • 忘记处理重边与自环：统计度数、判环时会重复计数。
  • 拓扑排序用了栈而不是队列：结果仍合法但不保证字典序，要求最小序时要用优先队列。
  • 求「谁能到达 x」时没反向建图：正向 DFS 得到的是 x 能到谁，方向反了。

例题拆解

查找文献（Luogu P5318）：给定有向图，从 1 号点出发，分别输出 DFS 与 BFS 的访问序列，要求每次优先访问编号更小的节点。 转化：标准的图遍历，唯一约束是邻居的访问顺序。 做法：读入后对每个点的邻接表排序（去重更稳），再分别用栈式 DFS 与队列 BFS 记录首次访问顺序。因为要求编号小的先访问，不能直接用 vector 的插入顺序。 复杂度：O(n + m + m log m)，排序是主要额外开销。

图的遍历（Luogu P3916）：对每个点，求它能到达的编号最大的点。 转化：正向做需要每个点各跑一次遍历，太慢；反过来想，「x 能到达 y」等价于「在反图上 y 能到达 x」。 做法：反向建图，从编号 n 到 1 依次作为起点 BFS，把沿途所有未标记的点答案赋为当前起点并标记。每个点只会被赋值一次，因为编号从大到小枚举，第一次遇到的一定是最大编号。 复杂度：O(n + m)。

自测清单

  • 能根据数据范围在邻接矩阵、邻接表、前向星之间做选择
  • 能手写 DFS 与 BFS 并正确维护 vis
  • 能解释 BFS 为什么能求无权图最短路
  • 会用拓扑排序判环，并知道怎么保证字典序
  • 能想到「反向建图」这类方向转换技巧
