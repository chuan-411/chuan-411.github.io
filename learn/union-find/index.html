并查集

只回答「我们是不是一伙的」：用森林表示集合，路径压缩后近似 O(1)。 · 路径压缩 + 按大小合并，单次操作均摊 O(α(n))

一句话理解

并查集只维护一种信息：两个元素在不在同一个集合里。它把每个集合画成一棵树，根就是「代表元」，判同伙只需看根是否相同。

核心思想

每个集合用一棵有根树表示，树根是代表元。find(x) 沿着父亲指针一路向上直到根，得到 x 所在集合；unite(a, b) 则把一棵树的根挂到另一棵树的根下面。合并的本质是「改一个父亲指针」，所以它极快，但也意味着只能合并，不能拆分。

两件优化决定了复杂度。路径压缩：find 时把路径上所有点直接连到根，下次再查就一步到位；按大小（或按秩）合并：把小树挂到大树下面，保证树高是 O(log n)。两者结合后，单次操作的均摊代价是反阿克曼函数 α(n)，在任何实际数据范围内都不超过 4，可以当作常数。

并查集有两个常见扩展。扩展域：一个元素拆成多个「角色」，例如 x、x+n、x+2n 分别表示三种可能的身份，不同角色之间的合并就编码了约束关系。带权并查集：在父亲指针之外再记一个权值 d[x]（如「x 与父亲的差值」），find 时顺路把它累加到根，于是能回答「x 与 y 的差是多少」。

典型应用包括 Kruskal 求最小生成树、连通块计数、判无向图是否有环、以及各种「关系传递」的判定题。注意它不支持删除与分裂；确需撤销时要用可撤销并查集或线段树分治。

模板与实现

1. 路径压缩 + 按大小合并（最常用）

const int N = 1e6 + 5;
int fa[N], sz[N];
void init(int n) {
    for (int i = 1; i <= n; ++i) fa[i] = i, sz[i] = 1;
}
int find(int x) {                       // 递归版，语义最清晰
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}
bool unite(int a, int b) {
    a = find(a), b = find(b);
    if (a == b) return false;           // 已在同一集合
    if (sz[a] < sz[b]) swap(a, b);      // 小树挂大树
    fa[b] = a;
    sz[a] += sz[b];
    return true;
}

2. 带权并查集

int fa[N], d[N];      // d[x] 表示 x 到父亲的权值
int find(int x) {
    if (fa[x] == x) return x;
    int p = fa[x];              // 先存下父亲，递归后它会被路径压缩改写
    fa[x] = find(fa[x]);
    d[x] += d[p];               // 再补上「父亲到根」这段权值
    return fa[x];
}
// 合并时把 ra 挂到 rb 下，需要解出 d[ra] 使约束成立

链很深（如 n = 1e6 且尚未压缩）时递归 find 可能爆栈，改成先找根再回头赋值的迭代写法。

复杂度与边界

  • 单次操作均摊 O(α(n))，可视作 O(1)；空间 O(n)。
  • 只做路径压缩时单次均摊 O(log n)，只做按秩合并时树高 O(log n)；两者都写才能到 O(α(n))。
  • 需要「撤销合并」时用可撤销并查集（不能路径压缩，只能按秩合并）。
  • 需要维护集合大小、权值和、最大值时，在根上多存一个数组即可。
  • 需要支持删除元素时，考虑为每个元素建虚点或改用线段树分治。

易错点

  • 忘记初始化：fa[i] = i 漏写，find 会走到 0 或死循环。
  • 比较写成 fa[x] == fa[y]：判连通必须比较 find(x) 与 find(y)。
  • 把 sz 当成每个节点的子树大小：路径压缩后只有根上的 sz 有意义。
  • 递归 find 爆栈：数据规模到 1e6 且形成长链时，改用迭代版。
  • 带权并查集累加顺序错：必须先递归、再 d[x] += d[p]，反过来会用到旧的父亲值。
  • 多测不清空：fa、sz、d 与计数器都要按 n 重置，只清到 n 比 memset 整个数组快得多。

例题拆解

亲戚（Luogu P1551）：给出 m 对亲戚关系，询问 q 次两人是否属于同一家族。 转化：关系具有传递性，正是并查集的定义。 做法：对每对关系 unite，询问时比较 find 是否相等，输出 Yes 或 No。 复杂度：O((m + q) α(n))。

食物链（Luogu P2024）：n 个动物分属 A、B、C 三类，A 吃 B、B 吃 C、C 吃 A；给出 k 句话，形如「x 与 y 同类」或「x 吃 y」，统计与已有真话矛盾（或编号越界）的假话条数。 转化：每个动物有三种可能的身份，用 3 倍空间的扩展域编码；一句话等价于若干对「角色」的合并，冲突即假话。 做法：x、x+n、x+2n 分别代表 x 属于 A/B/C。同类就合并三对角色；「x 吃 y」就合并 (x, y+n)、(x+n, y+2n)、(x+2n, y)。合并前先判矛盾：同类时若 find(x) == find(y+n) 或 find(x) == find(y+2n)，说明二者已被判定异类；「x 吃 y」时若 find(x) == find(y)（同类）或 find(x) == find(y+2n)（反向捕食），也是假话。也可用带权并查集把关系记成模 3 的差值，空间只要 n。 复杂度：O(k α(n))。

自测清单

  • 能手写 find 与 unite，并说清两处优化各自的作用
  • 能解释为什么并查集不能删除元素
  • 会用扩展域把「敌人 / 朋友」类关系编码
  • 能写出带权并查集并正确推出合并时的权值
  • 知道什么时候必须放弃路径压缩（可撤销场景）
